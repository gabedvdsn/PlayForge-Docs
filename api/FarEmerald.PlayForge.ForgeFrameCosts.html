Class ForgeFrameCosts

FarEmerald.PlayForge.dll

A frame's costliest processes, which go into the Profiler's capture as the frame's metadata while the Profiler records, for the PlayForge Processes module to list. The costs go under Tag, the costliest first, and each one's type's name, in UTF-8, under the tags after it in the same order, so a saved capture still names them. The scene's ProcessControl puts them in as its frame ends; while the Profiler doesn't record, nothing is timed for them.
