Class Bootstrapper

Namespace
FarEmerald.PlayForge
Assembly
FarEmerald.PlayForge.dll

Brings PlayForge up as a scene starts: ProcessControl, then the GameRoot, which runs as the Game Root entity of the Forge Project the Bootstrapper names. It names prefabs for both, which code makes in the PlayForge folder's Bootstrap folder as the first Forge Project is made; without them it makes each itself, so a scene needs nothing but a Bootstrapper. PlayForge ships no prefab. A scene of processes and task sequences alone, with no entities, can take the ProcessBootstrapper instead.

Guide: Processes

Named in: Getting Started: Quickstart: a damage ability in ~10 minutes
