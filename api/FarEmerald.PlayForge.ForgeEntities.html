Every live entity, on both hubs: each joins as its core initializes and leaves as it ends. An area search goes through it, as Auto Target and Auto Target by Affinity do: with no range they searched the scene for MonoBehaviour entities alone, so a runtime entity was never found; and with a range they searched with physics alone, which finds no runtime entity, as it has no collider.
