Class ForgeReach

Namespace
FarEmerald.PlayForge

What reads an ability's reach, its first IAbilityReach component's: how far it reaches, and whether a target or a point lies beyond it, from its caster. An ability with none reaches anywhere. Each read that takes a reach reads that one, as a component of more than one reach asks its own.
