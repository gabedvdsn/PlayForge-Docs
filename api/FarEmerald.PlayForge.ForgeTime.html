The clock PlayForge's runtime reads: Unity's, unless Use(IForgeClock) puts another in. The runtime read Unity's Time in a dozen files, so nothing could step it to a clock of its own, as a deterministic replay, a server or a test needs. A source-scanning test keeps Time out of the runtime.
