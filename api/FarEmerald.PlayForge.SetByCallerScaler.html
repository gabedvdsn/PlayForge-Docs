A value the caller passes in under a tag, as Unreal's SetByCaller is: code that knows the amount as it applies an effect or activates an ability sets it, and the number reads it.

What it checks: whether the context it's read in holds a value under exactly Key. A context holds the values set on what it was built from: an effect's spec (spec.SetByCaller(tag, value), before it's applied), an ability activation's data (data.SetByCaller(tag, value), which each effect the ability makes takes as it's made, and which the ability's tasks read), or the data that spawned a process. Only the key itself matches: a value set under a tag above or below it in the tag tree doesn't. A value set to 0 is a value, and is read. Where the context holds no value under the key, or holds no values at all, as an entity on its own, it reads Default.

It is a number kind, so it reads from any context that holds values: it read only an effect spec's, so a task's or a process's number read its default. Its default is a number of any kind, read with the scaler as its owner, so where nothing is set it can read a value by level.
