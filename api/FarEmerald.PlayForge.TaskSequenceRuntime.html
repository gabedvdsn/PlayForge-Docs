Clock

The clock this run goes by, read as it's asked: its own, as whatever runs it sets it, then its packet's (Clock), then its sequence's (WithClock(IForgeClock)), then its packet's owner's, an ability's caster's, then the game's. Its waits, delays, timeouts and ElapsedTime, its tasks' tweens and its synced tasks go by it. Set it to give this run a clock of its own, as an ability's Run Sequence task does with its pick, so a packet others share keeps its own; null takes the rest in turn.

CreateLinkedTokenSource(CancellationToken, CancellationToken)

A token source linked to token, and to other where one is given, so it's cancelled as either is, whose token belongs to the run token belongs to. A task that links its token, as for a timeout or a wait of its own, keeps its run's clock and pause this way: the library's waits and tweens, ClockOfRun(CancellationToken, ProcessDataPacket), IsPausedRun(CancellationToken) and DataOfRun(CancellationToken) know its token as the run's. A token that CancellationTokenSource.CreateLinkedTokenSource links belongs to no run, so its waits go by the game's clock and don't hold while the run is paused. Dispose it once done, as any token source: the run lets go of its token then, or as the run ends. For a token of no run, it's a plain linked source.
