Interface IForgeClock

Namespace
FarEmerald.PlayForge
Assembly
FarEmerald.PlayForge.dll

A source of time, which PlayForge's runtime reads instead of Unity's Time. The default reads Unity's; a test, a replay or a server puts one of its own in with Use(IForgeClock). A sequence or a packet can name one of its own too (Clock, WithClock(IForgeClock)), as a menu's runs on UnscaledClock.

FollowsTicks

Whether a sequence on this clock waits for the game's ticks where ProcessControl's tick rate is set: true for a clock of the game's time. The ticks run on that time and stop with it, so a clock that runs while it stands, as UnscaledClock does, has its sequences wait for Unity's frames instead.
