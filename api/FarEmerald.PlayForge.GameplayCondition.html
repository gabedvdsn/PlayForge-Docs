Class GameplayCondition

Namespace
FarEmerald.PlayForge

FarEmerald.PlayForge.dll

A condition read against a number's context: whether something holds where the number is read, as "the target's Health is below 0.3 of its base". A Conditional scaler reads one to choose its branch. It is a class, so a project adds its own as it adds a kind of number: override Evaluate(in NumberContext), and name it, file it and say what it reads with GameplayConditionAttribute:

[Serializable]
[GameplayCondition("Target Is Caster", Reads = NumberReads.Caster | NumberReads.Target)]
public class TargetIsCaster : GameplayCondition
{
    protected override bool Evaluate(in NumberContext context) => ReferenceEquals(context.Caster, context.Target);

    public override string Describe() => "the target is the caster";
}

Where the context lacks what a condition reads, as a target's tag where there's no target, it doesn't hold, and it logs once. A condition's own numbers read with the condition as their owner. Its fields draw in the inspector with no editor code, with [Tooltip] and [ForgeShowWhen]; it is saved by its class's name, as a [SerializeReference] value is, so renaming the class needs Unity's [MovedFrom].
