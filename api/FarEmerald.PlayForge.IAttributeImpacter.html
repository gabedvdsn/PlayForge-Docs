Interface IAttributeImpacter

Namespace
FarEmerald.PlayForge
Assembly
FarEmerald.PlayForge.dll

A single magnitude-evaluation unit owned by an IAttributeImpactCarrier. One carrier may expose many impacters; the cached attribute aggregator walks them and applies their contributions in op-precedence order:

  1. Add — summed first → DirtyValue.
  2. Multiply — composed via MultiplyBehaviour.
  3. FlatBonus — added after multiplies.
  4. Override — wins (resolved by SortOrder).

Reversal under recompute model — retained carriers reverse automatically when removed (Recompute simply walks the new shorter retention list). One-shot committed contributions persist via CachedAttributeValue.committedOneShotDelta and are reversed only by an explicit synthetic-carrier rollback (see GameplayEffectImpact.ReverseImpactOnRemoval).
