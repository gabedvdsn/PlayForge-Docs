An attribute set element: a foldout row with the attribute and the element's menu, and while it's folded one line of what it starts at; open, what it starts at at each level, then Link Current to Base, Current, which the link hides, and Base, each side a magnitude field as an effect's are, then its bounds, its constraints, its retention group and its collision.

What it starts at is worked out by the runtime (AttributeStartValues): a stand-in entity at each level of the set it's previewed in, with the set's sub-sets. A note says when another element's value is the one used, and a message when a scaler reads an attribute the set doesn't give. The element showed its magnitudes as a formula, as "10 + Level", and Current and Base one at a time on a switch.

It writes nothing while it draws, and only a typed magnitude is kept within the bounds, as part of the same edit.
