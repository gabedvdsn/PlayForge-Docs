Represents a gameplay tag with hierarchical support using dot notation. Example: "Status.Debuff.Burn" where "Status" is the root, "Debuff" is a child, and "Burn" is the leaf.

Path

The path its hierarchy goes by: a unique tag's display path, what the designer sees, as its name carries hash padding; any other tag's name. So a New-Tag "Status.Debuff.Burn" is under a New-Tag "Status.Debuff", and under a plain "Status". Equality still goes by the name.

PathOf(string, string)

The path a tag of a name and a display text goes by, as Path, for a tag read from its parts, as a serialized one is. A unique tag's name is its display text with hash padding after it, which has no dot, or the text cut short at its length (TagRegistry.TagUtil.GenerateDeterministicTag); an asset tag's display is its leaf alone, so its name is its path. Nothing is allocated, as a query reads paths often.
