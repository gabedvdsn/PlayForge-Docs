An entity's Local Data as its GAS holds it at runtime, a value under each key tag: loaded from its identity's rows as it initializes (Init), then written with Set and read with TryGet, or with GetOrInit, which adds a value where the key has none. A hub's GetLocalDataStructure gives it.
