Base class for tag-based workers that activate/deactivate based on tag state. Tag workers run as long as their tag requirements are met.

Lifecycle:

  • Activate() called once when requirements become met
  • Tick() called periodically while active (based on TickPause)
  • Resolve() called once when requirements are no longer met

Common use cases:

  • Show fire particles when Fire tag weight >= 3
  • Play warning sound when LowHealth tag is present
  • Grant temporary ability while Empowered tag is active

EvaluateEveryFrame

Whether the worker is evaluated at the end of every frame, as every worker was. Off, as it is by default, it's evaluated at the end of a frame in which the entity's tags changed, since ValidateWorkFor(ITagHandler) reads them. A worker whose validity reads more than the tags turns it on. Read as the worker is provided.
