The base of an effect's Stack Behaviours, the rules its stacking containers follow: Stack Bounds, Scaled Stack Amount and Starting Stacks. A behaviour of your own derives from it and overrides InitializeContainer, to set a new container up, and GetStacks, to settle how many stacks an application adds from the amount the behaviours before it settled on; GetCorrectContainer picks the container an application stacks into, the first by default.
