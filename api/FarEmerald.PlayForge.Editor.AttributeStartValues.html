What each attribute an entity built from an attribute set starts at, at each of the set's levels, worked out as the runtime works it out: a stand-in entity at the level, whose attribute system is set up from the set as the GAS sets one up, with the set's sub-sets and collisions, and each element's scalers, bounds and rounding. Nothing else acts on the stand-in, no worker, effect or item, so a value is the one the set gives before anything changes it. A set that another holds starts as part of it, so its values can be worked out in each set that holds it, and the attribute set inspector previews a set in one of them (PreviewIn(AttributeSet, AttributeSet)).
