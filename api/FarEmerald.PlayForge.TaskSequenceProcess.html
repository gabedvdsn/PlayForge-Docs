Class TaskSequenceProcess

Namespace
FarEmerald.PlayForge
Assembly
FarEmerald.PlayForge.dll

Wraps a TaskSequence or TaskSequenceChain for execution via ProcessControl. Supports both async (SelfTerminating/RunThenWait) and sync (Synchronous) lifecycles.

Async mode: RunProcess executes the sequence via Execute path. Sync mode: RunProcess is skipped; WhenUpdate drives the SyncedTaskSequence runner via Step path.

Uses SequenceDataPacket for direct sequence/stage control.
