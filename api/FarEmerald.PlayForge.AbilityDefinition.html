BufferWindow

Under the Queue policy, how long a request that can't start yet waits in the input buffer, in seconds of the caster's time: a press while another ability holds the claim, or while a running stage blocks this one, fires once it can, if that comes in time. A request can name a window of its own. The Queue policy waited for good, behind every earlier press. Read at the ability's level.

What activates the ability on its own: a gameplay event sent to its entity, or a tag its entity gains, under the trigger's tag or one under it. Each tries the ability as a request would, so its checks and its When Busy still hold. An ability activated only when code asked for it.
