A whole gameplay number: ScalableFloat for counts, as an effect's ticks or a stack's size. It takes every kind a ScalableFloat does, and rounds what it reads as Rounding says, so a kind is written once. It is the whole-number magnitude field it grew from, with the same saved fields.
