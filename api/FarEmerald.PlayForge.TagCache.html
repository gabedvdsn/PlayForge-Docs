EvaluateTagWorkers()

Evaluate tag worker states and queue activate/resolve actions. Called during end-of-frame processing.

public void EvaluateTagWorkers()

Remarks

It evaluates them only when the tags changed, a worker came or went, or the last evaluation queued an action, which it then sees land: in any other frame, every worker would come out as it was. The workers were evaluated at the end of every frame, a poll for the tags they name. A worker whose validity reads more than the tags asks for every frame with EvaluateEveryFrame.
