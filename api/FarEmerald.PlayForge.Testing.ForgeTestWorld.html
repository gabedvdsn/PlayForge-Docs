Class ForgeTestWorld

Namespace
FarEmerald.PlayForge.Testing

FarEmerald.PlayForge.Testing.dll

One live PlayForge for one test: a real ProcessControl and GameRoot brought up by the real Bootstrapper, stepped by Unity's player loop a frame at a time. It makes what a test needs, entities on either hub, from an identity asset or from attributes, and plays them as a game does: Hit(IGameplayAbilitySystem, IGameplayAbilitySystem, GameplayEffect) applies an effect, Cast(IGameplayAbilitySystem, Ability, IGameplayAbilitySystem, int) gives an ability and starts it, Use(IGameplayAbilitySystem, Ability, IGameplayAbilitySystem) starts one the entity has, and Hold(IGameplayAbilitySystem, Item, int) equips an item. Its Clock(float) and Rolls(params float[]) make time and chance the test's.

It ends as a test asks, or as it's disposed (await using): every process it began, every object and asset it made, and the framework's static state, so tests run in any order. Audit() first says what broke of its Invariants. ForgeTest makes one for each test, audits it and ends it. Step frames, and let ProcessControl step what runs: never call a process's update by hand.

End()

Takes everything down, whatever state the test left it in: every process, object and asset the world made, and PlayForge's static state, and gives back the clock and the rolls. Forcing every process to end at once runs each way one ends, and what those report says nothing of the test, so it's let pass. Ending twice does nothing.
