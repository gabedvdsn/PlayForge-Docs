A scaler tried in the editor: read at each level of a range against stand-ins for its caster and its target, which hold the values typed for them or filled from an entity's attribute set, and with the values a caller sets. A read finds what the scaler asks for, each attribute on its side and each caller's key, and adds a row for each the first time, filled from its side's entity where it has one. A row it lacks reads as an entity without the attribute does, and a caller's key not set reads as a caller that didn't set it.

A stand-in holds attributes alone: a number that reads an effect on a side, an item, a tag, a retention group's part or Local Data reads as it would on an entity with none of them. A Scaler asset's try, from For(ScalerAsset), is kept for the session with Keep(), and never written into the asset.
