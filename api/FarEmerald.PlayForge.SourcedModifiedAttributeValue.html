A change to an attribute on its way through the attribute system: a Current and a Base, and the carrier it comes from, which names its source, its target, its impact types and its retention group. Code changes an attribute directly with one, through the entity's TryModifyAttribute: GenerateSimple makes a raw delta with no impact type, which workers take as they take an effect's change, and GenerateUnworkable one the system makes on its own account, unworkable, as ImpactIsWorkable says, so it counts as no hit. Over an effect's spec, the spec's impacters say what commits, and these values only travel with them.

SourcedModifiedAttributeValue(SourcedModifiedAttributeValue, float, float, bool)

A value over another's carrier. Where that carrier has impacters of its own, as an effect's spec has, the attribute system commits them as authored, and these values only travel with them: deriving from a hit and giving it +10 lands the hit again. A change of a value of its own takes GenerateSimple(ISource, IAttribute, float, float) or GenerateUnworkable(ISource, IAttribute, float, float), whose carriers have none.

GenerateSimple(ISource, IAttribute, float, float)

A raw delta: a change made directly, with no effect behind it. Workers see it as they see an effect's change, with no impact type, so a worker that takes any type acts on it and one that wants a type doesn't. It was unworkable and typed DisallowImpact, so no worker ever saw one.

It makes a new carrier on every call. A raw delta made every frame, as regeneration might be, keeps one instead: make it once with GenerateSourceDerivation(ISource, IAttribute), the carrier this makes, and hand the GAS a new value over it each time. That allocates nothing.
