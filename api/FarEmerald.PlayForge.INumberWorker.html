Interface INumberWorker

Namespace

FarEmerald.PlayForge.dll

A worker that answers numbers: a number of the Worker kind, or an Asset Part number's Worker Value, asks it for a value under a key, and it answers from what it knows, as how much health its effect's target has lost since the effect began. Any worker can implement it: an effect's workers answer about their effect, and an entity's workers, those its worker groups give it, about the entity. Every number field can ask, so a worker can drive an effect's magnitude, a task's range, a threshold or a cue's parameter.

The context it's asked in is what it's asked about: for an effect's worker, the effect's own context, whose Carrier is the effect's spec, where its state for that application is (GetWorkerState<T>(AbstractEffectWorker)); for an entity's worker, the asking number's context. It answers false for a key it doesn't know, and the asker reads its default.
