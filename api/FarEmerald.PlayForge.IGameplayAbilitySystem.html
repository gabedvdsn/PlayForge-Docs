Interface IGameplayAbilitySystem

Namespace
FarEmerald.PlayForge
Assembly
FarEmerald.PlayForge.dll

An entity's gameplay ability system as code meets it, whichever hub runs it: the GameplayAbilitySystem component on a GameObject or a RuntimeGameplayAbilitySystem made in code. Through it code reaches the entity's attribute, ability, item and effect systems, its tags, levels and effects, its callbacks, clock, services and Local Data, and its turning, death and revival; ToGASObject gives the component, where there is one. Code that works with any entity takes one.

Face(ITarget, float, float)

Turns the entity to face a target, which it follows as it moves, flat, at degreesPerSecond of its own time, 0 at once, until it faces it within within degrees. Another order replaces the turn; its death and StopTurning() end it. A turner of the game's own on its object, an IForgeTurner, takes each step where it has one; otherwise its facing is set. The entity itself, or a target with no place, turns nothing.
