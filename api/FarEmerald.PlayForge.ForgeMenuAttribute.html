Files a kind in the pickers that offer it, an ability task's, a worker's, a component's, a cue's, a number's and the rest: under the submenus its path names, a slash between each, as "Effects" or "Effects/Damage"; with a name to show in place of its class's; and with a description the picker's Context says while it's highlighted.

A path holds for the classes made from the one that names it, unless one names its own, "" for the picker's top; a kind that names only a name or a description keeps its base's path. A name and a description are a kind's own. A picker lists a menu's submenus in name order, then its kinds; its search finds a kind whatever its submenu.

It replaces ForgeCategory, the ability tasks' one level of groups, and the Category of a number's kind and of a condition, each of which filed one family alone. 

[Serializable]
[ForgeMenu("Effects/Damage", Description = "Deals its damage to each target, once")]
public class StrikeTask : AbstractAbilityTask { ... }
