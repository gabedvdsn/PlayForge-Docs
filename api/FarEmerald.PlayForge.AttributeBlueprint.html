What an attribute's root value on an entity is worked out from: the value before any item, effect or worker acts on it, as an attribute set element gives it. An element's own blueprint reads the element's Current and Base, each resolved on its own. Where elements collide, the attribute takes a blueprint that joins theirs (Sum(IReadOnlyList<AttributeBlueprint>) or Average(IReadOnlyList<AttributeBlueprint>)), each part worked out on its own, a joined one among them; its bounds, rounding and retention group are its first part's.

Per-side resolution rules (applied identically for Current and Base):

  1. If the side's scaler is null OR its RealMagnitude is UseMagnitude → return Magnitude.
  2. Otherwise call the cached scaler (Initial vs Active path) and project the side's slot from the returned AttributeValue (Current → CurrentValue, Base → BaseValue), then combine with the side's Magnitude via its RealMagnitude operation.
