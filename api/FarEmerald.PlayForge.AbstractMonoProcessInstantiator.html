What makes a mono process's object and takes it back, as a pool hands out an idle object and keeps it again as its process ends. Derive from it and override PrepareNew, which makes or hands out an object of the prefab registered, PrepareExisting, which readies one already in a scene, and CleanProcess, which takes the object back as its process ends. A registration's InstantiatedBy, a process's own Instantiator or its handler's gives one; with none, the object is cloned and destroyed.
