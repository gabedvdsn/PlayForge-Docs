Another number field of the same object: the number joins it as its Combine says, times it or plus it, so a Clamped scaler's Max can be 2 × Min and a stack bound's Max Min + 3. The field is a number (ScalableFloat or ScalableInt), read in the same context, so a relative Max follows a Min that scales by level, or a plain float or int.

It reads its object through the owner its object's own code gives as it reads its numbers, MaxValue.Evaluate(context, this), and a field whose code gives one declares Owner in its NumberContextAttribute. With no owner, with a field name its object no longer has, or in a loop of numbers that read each other, which stops 8 deep, its number reads its own value and logs once. It finds its field by name through an accessor made once for each type and field, so a read allocates nothing after the first.
