Class PlayForgeSettings

Namespace
FarEmerald.PlayForge.Editor
Assembly
FarEmerald.PlayForge.Editor.dll

PlayForge's authoring settings, a Forge Project's, so they travel with the project under version control: where each type's new assets go, the defaults a new asset copies and Import lists first, and the effects a new Cost or Cooldown copies. A new asset's file is its name alone. The Project Settings page edits them; the view toggles stay in Preferences (PlayForgePreferences). The file and the EditorPrefs a project took them from once are gone with that taking.
