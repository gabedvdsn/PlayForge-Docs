Interface IGameplayProcess

Namespace
FarEmerald.PlayForge

FarEmerald.PlayForge.dll

A process as ProcessControl runs it: the packet and relay it's handed as it registers (SendProcessData), its hooks as it initializes, waits, terminates and is destroyed, its steps at its timing (WhenUpdate, WhenLateUpdate, WhenFixedUpdate), the run ProcessControl awaits (RunProcess), and whether it keeps its run through a pause (TryHandlePause, TryHandleResume). It's a process handler too, so the processes registered under it end with it. AbstractMonoProcess and AbstractRuntimeProcess implement it, and a process of your own derives from one of them.

TryHandlePause()

Called via ProcessControl when a running process is paused. Return true to keep the run and hold it yourself, which it does by watching its relay. Return false, as the default does, and the run is cancelled and a new one starts on resume.

TryHandleResume()

Called via ProcessControl on resume, for a run that was kept. Return true once it has picked up where it stopped. Return false and it's cancelled, and a new one starts.
