What a number is read against: what its site has. A kind of number reads it; it is the whole of a kind's API, so adding to it later breaks no kind. It offers the caster, the target and the level; the carrier, where there is one, and what it has dealt; the caller's magnitudes and Local Data, each by key; an attribute's value or a retention group's part of it, on either side, and through SystemOf(NumberSide) the effects there; the activation's data, where a task reads it; and the owner, the object the field belongs to. Has(NumberReads) says which of these this site provides.

A site builds one with Of, from an effect spec, a container, an activation's data, a worker's context, an entity, a cue or a process, and reads its numbers through it: Range.Evaluate(NumberContext.Of(data)). A test builds one with For(ISource, ITarget, int, int). It is a struct, and a number read through it allocates nothing.
