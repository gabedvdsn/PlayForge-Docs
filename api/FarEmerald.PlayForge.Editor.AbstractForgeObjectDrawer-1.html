A reference to a PlayForge asset, or to a Value Pipeline, Crowd Control Rules or Effect Modifier: Unity's object field, with its type's icon, and beside it a plain button, Open while it names an asset, which shows the asset in a window of its own, or New while it's empty, which asks for a new one's name in The Forge's New dialog, makes it where The Forge makes its type and uses it. A drawer adds its own actions to the field's right-click menu. It was a button that opened a dropdown list of its own, with hover colors and Clear and Open icon buttons set in C#.
