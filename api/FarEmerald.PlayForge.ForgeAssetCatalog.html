Names the assets a save refers to, attributes, effects, abilities and items, by IDs that last across sessions, as a reference doesn't. A save names each by its ID here, and a load finds it by that.

In the editor, Add Every PlayForge Asset, in the catalog's menu, names each PlayForge asset in the project by its GUID, which lasts as the asset is renamed or moved. A game can add its own as it runs.

A ForgeProject is the catalog the Create menu makes, of the assets in its folder, which it keeps current as they're made, moved in and deleted; a catalog made before goes on naming what it names.
