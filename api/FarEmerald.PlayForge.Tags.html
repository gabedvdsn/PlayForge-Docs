PlayForge's own tags, grouped by kind. Each is its text padded to 64 characters by a hash of it, a name every asset that uses the tag stores, so a text changed is another tag; a test pins each one's name and kind. Each is exposed to the editor's pickers for its kind.

Named in: Cues: Data packets · Attributes: Roles · Getting Started: Quickstart: a damage ability in ~10 minutes · Effect & Attribute Pipeline: 5. Recalculation (regulated attributes) · Effect & Attribute Pipeline: 6. Initialization & auto-scaling
