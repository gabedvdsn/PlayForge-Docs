An Attribute asset: one number an entity can have, as Health, Mana or Strength. It holds no value: an entity takes its starting Current and Base from its attribute set, and effects change them from there. Sets, effects, workers and conditions name the asset itself, and some lookups compare attributes by name, so give each its own.

Its Role says what it is, how bonuses to it add up and how a number reads it: a Value, a Bonus Share, a Multiplier, a Resistance, or a Barrier, which takes each workable loss to the attribute it absorbs for first and can decay. Gains Scaled By names an attribute that multiplies each workable gain to its Current, as Health's by Healing Received.
