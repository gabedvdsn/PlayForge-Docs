The tag side of an entity, as a GAS hub's: the tags it holds (GetAppliedTags), how many times a tag is granted (GetTagWeight, which a hub gives as −1 for a tag it doesn't hold), whether a tag query holds of it (QueryTags), and a rebuild of its tags from what grants them (CompileGrantedTags). Every target is one, and a tag worker checks its requirements against it.
