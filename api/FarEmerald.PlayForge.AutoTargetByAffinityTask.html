Auto-targeting task that filters by affiliation (ally, enemy, neutral). Uses OverlapSphere to gather ITarget candidates, then filters by matching or opposing affiliation tags relative to the caster.

Common use cases:

  • Heal nearest ally
  • AoE damage to enemies only
  • Buff all allies in range
