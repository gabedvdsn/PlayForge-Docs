One authored impact: WHAT attribute, HOW (operation/slot/magnitude), WHEN (Delivery), and WHO it belongs to (retention group, for the per-group attribution surface). A GameplayEffectImpact holds a list of these — one effect can carry e.g. a Continuous "+10% speed" AND a Periodic "5 HP per tick" without contained-effect workarounds.
