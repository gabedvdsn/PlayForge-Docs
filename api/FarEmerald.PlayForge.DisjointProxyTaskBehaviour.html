A disjoint, as in Dota: the shots already aimed at an entity lose it, fly on to where it stood, and land on nothing. A shot is found through the intent it registers with its target, which only a homing shot does (AbstractTargetedMonoProcess), and only one whose data marks it IS_DISJOINTABLE is disjointed. A skill shot, one that hits whatever it crosses, registers no intent, and lands as usual.
