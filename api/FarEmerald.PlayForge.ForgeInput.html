The input click targeting reads: the project's own, unless Use(IForgeInput) puts another in. Targeting read the Input Manager's mouse and Camera.main itself, so a game on the Input System, with a camera of its own or a test couldn't stand in, and a scene with no main camera threw at the click. A source-scanning test keeps Unity's input out of the rest of the runtime.
