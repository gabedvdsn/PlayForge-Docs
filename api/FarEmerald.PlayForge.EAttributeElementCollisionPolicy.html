Enum EAttributeElementCollisionPolicy

Namespace
FarEmerald.PlayForge
Assembly
FarEmerald.PlayForge.dll

An attribute set element's Collision: how it joins the other elements that give its attribute, across a set and its sub-sets. UseThis stands over every other element; UseSetCollisionSetting settles by the collision settings of the set the entity names; Combine adds its value to what those settle on, or to the others that combine; UseExisting gives way to any other, and counts only where nothing else gives the attribute. Several elements set to Use This, or to Use Existing, settle among themselves by the set's settings.
