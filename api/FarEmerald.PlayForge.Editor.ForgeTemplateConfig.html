IsExcluded(string, Type)

Returns true if the given property path should be excluded from template propagation for the given asset type. Checks both common exclusions and type-specific exclusions.

Matching rules:

  • Exact match: "Name" matches "Name"
  • Prefix match: "Textures" matches "Textures.Array.data[0]" etc.
  • Sub-field match: "Definition.Name" matches "Definition.Name" and any children
