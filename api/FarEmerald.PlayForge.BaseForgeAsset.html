Class BaseForgeAsset

Namespace
FarEmerald.PlayForge
Assembly
FarEmerald.PlayForge.dll

The base of every PlayForge asset, a ScriptableObject: attributes directly, and abilities, effects, items, attribute sets and entities through BaseForgeLevelProvider. It holds the asset's Local Data rows, read by key with TryGetLocalData, and its template, an asset of the same type whose fields it takes when the template is pushed, apart from those it overrides (SetTemplate, IsFieldOverridden). A type made from it gives its name, description, default icon and the tags it grants.
