FarEmerald.PlayForge.Testing

The base of a test that plays PlayForge content: a live ForgeTestWorld before each test, and after it the world's invariants audited and the world ended. A test is a PlayMode [UnityTest] whose body runs through Live(Func<UniTask>), from a frame's end:

[UnityTest]
public IEnumerator Burn_ticks_twice() => Live(async () =>
{
    var health = Make.Attribute("Health");
    var target = World.Entity(Hub.Runtime, Make.Set(Make.Pool(health, 100f, 100f)));
    var burn = Make.Effect("Burn", new EffectConfig { Policy = EEffectDurationPolicy.Durational, Target = health,
        Magnitude = -10f, Duration = 1f, PeriodicTicks = true, Ticks = 2 });
    World.Hit(World.Entity(Hub.Runtime), target, burn);
    await Frames.Until(() => World.Value(target, health) <= 80f, 90, "two ticks land");
});

A test with a base class of its own makes a world with Start(float) instead.
