The default impacter shape — wraps a ScalableFloat (the editor-authored magnitude + scaler + RealMagnitude triplet that already lives on GameplayEffectImpact) and exposes it through the impacter contract.

One ScalerImpacter per GameplayEffectImpact is the current shape.
