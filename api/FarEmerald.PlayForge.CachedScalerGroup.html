Class CachedScalerGroup

Namespace
FarEmerald.PlayForge

FarEmerald.PlayForge.dll

Combines multiple cached scalers using the active AttributeValue interface. Members are evaluated component-wise (Current and Base independently) and combined per the member's ECalculationOperation. Override members short-circuit other operations and resolve via OverrideMemberCollisionPolicy. Regulation propagates to all members so any captured-attribute change triggers a refresh.

With no members, or none that holds a kind, it is no kind at all, so its element's side reads its number, as the Group does. Its Ignore policy threw; it sets overriding members aside.
