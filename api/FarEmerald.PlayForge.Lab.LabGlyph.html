Class LabGlyph

Namespace
FarEmerald.PlayForge.Lab
Assembly
FarEmerald.PlayForge.Lab.dll

An inline vector glyph drawn in its resolved color, which the style sheet sets: the glyphs of PlayForge's editor, drawn the same way in the lab, whose panels run in a game as well as in the editor. A type's glyph differs in shape as well as color, so color is never its only sign.
