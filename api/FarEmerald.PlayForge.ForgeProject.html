A Forge Project: a set of PlayForge assets of its own, those under the folder its asset is in. The Forge shows the active project's assets alone, and makes new assets in it. A project's folder can hold another project's, and an asset is in the innermost project whose folder holds it. It's an asset catalog too, of its own assets, for saves, which it keeps current as they're made, moved in and deleted; Add Its Assets names them by hand.
