Namespace

How an ability's uses come back: how many it holds, how many are in hand, and what a use spends. A capability an ability's component implements, as Charges does; with none, an ability has SingleCooldown, one use, back as its Cooldown ends. The Cooldown check asks it what's in hand, an ability spends a use through it as it commits, and a HUD reads it through CooldownModel, whatever the ability's components are.
