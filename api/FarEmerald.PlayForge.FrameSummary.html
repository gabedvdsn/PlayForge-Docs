Class FrameSummary

Namespace
FarEmerald.PlayForge
Assembly
FarEmerald.PlayForge.dll

Captures all modifications and events that occurred during a frame for a single GAS.

Impact tracking is split by perspective: • Impact RECEIVED — indexed by ISource (who attacked me) • Impact DEALT — indexed by ITarget (who I attacked)

A self-impact (source == target on the same system) is recorded on both sides.
