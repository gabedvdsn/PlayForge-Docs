An authored gameplay number. It is a plain number by default, and it can also be one of the kinds the inspector's kind menu offers: a value by level, a multiple of an attribute, a value its caller sets, any scaler, or a kind a project writes (NumberKind). It is the magnitude field it grew from, under a new name, with the same saved fields: its number (Magnitude), its scaler, and how the two combine (RealMagnitude). So every magnitude saved before it loads as it was.

A float converts to one, so public ScalableFloat Range = 20f; and effect.Range = 5f; compile. There is no conversion back, as it would drop the kind: a read is Evaluate(in NumberContext), once, at the site's natural moment, as an effect as it's applied or a task as it starts.
