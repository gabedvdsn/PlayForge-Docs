The contexts a tag is offered in: one per kind of tag, what a tag is rather than where it's used. A tag field names the kinds it takes with [ForgeTagContext], and its picker offers the tags of those kinds: those assets use in such a field, those a Tag Library declares for them, and those code exposes with [ForgeTagExposed].

Usage: [ForgeTagContext(ForgeContext.Granted)] public Tag Stunned;

Each constant is its value without its spaces. A project's own contexts, made in a contexts field's New Context…, stand beside these.
