Numbers by level and item stats, to and from CSV, so a game is balanced in a spreadsheet.

A sheet of numbers by level has a row for each number of an asset that reads a Table or By Level: the asset's tag and name, the field as the inspector labels it, its kind, and what it reads at each level, its values times its number, as Laguna Blade's -450/-600/-750. A sheet of item stats has a row for each item and a column for each attribute its granted effects add to: a number, or one for each level, as 10/15/20.

A sheet read back finds each row's asset by its asset tag, or by its name where it gives none; a name two assets share, an asset that isn't there and a field it hasn't got are problems, not guesses. Its changes, listed, apply as one Undo step, each number's values set so it reads what the row says.
