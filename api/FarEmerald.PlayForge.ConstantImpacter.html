A precomputed-magnitude impacter. Used for synthetic deltas where there's no scaler pipeline to evaluate — e.g. auto-scale propagation, tracked-impact reversal on container removal, or external systems that just want to push a number into the attribute aggregator while still being a first-class carrier.

Construct one impacter per (operation, slot) pair you want to contribute. To express a (current=+10, base=+5) Add delta as a single carrier, hand that carrier two ConstantImpacters — one per slot.
