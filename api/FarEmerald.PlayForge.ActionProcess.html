Class ActionProcess

Namespace
FarEmerald.PlayForge
Assembly
FarEmerald.PlayForge.dll

A runtime process that calls an action in each of its Update steps, until it's ended. Made with the action alone, it's named Action, SelfTerminating, and stepped in Update at the first priority; the longer constructor gives its name, priority, timing and lifecycle.
