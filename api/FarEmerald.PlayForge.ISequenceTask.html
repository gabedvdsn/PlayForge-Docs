Interface ISequenceTask

Namespace
FarEmerald.PlayForge
Assembly
FarEmerald.PlayForge.dll

Unified interface for tasks that can be executed within a TaskSequence. Supports both async execution (via Execute) and synchronous per-frame stepping (via Step). Task authors implement whichever path(s) their task will be used under.
