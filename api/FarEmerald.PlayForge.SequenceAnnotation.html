Declarative annotation of what a sequence DOES — the introspection channel for code-driven sequences. Sequence bodies are opaque async lambdas; annotations let the author state gameplay intent so AbilityInspector can decipher abilities built on RunSequenceTask (tooltips, the Forge analysis tab, debugging).

The load-and-apply pattern: an asset-loader task (e.g. SetEffectsTask) puts effects into the data packet under a tag, and the sequence applies them via data.TryApplyEffects(target, tag). Annotating with that tag (AppliedEffectsTag) lets the inspector connect the loaded effect assets to this sequence's application — including how many times (MaxApplications, e.g. Chain Lightning's 4 jumps).
