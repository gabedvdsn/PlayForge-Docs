Class ForgeLog

Level-gated logging for PlayForge: all the runtime says goes through here, and this file alone writes to Unity's console, so a project sets how much it hears in one place: Preferences → PlayForge → Logging in the editor, kept and put back on a domain reload, or MinimumLevel from code.

Each message is of a system, effects, abilities, workers, numbers, processes, sequences and the rest, and a system can take a level of its own, SetLevel(ESystem, ELevel?), as the Creator Lab's log does; Logged hears each message let through, with the entity it's about where it names one.

What's said only when asked, a debug tool's output (TagCache.LogWeights, the Threshold Debugger worker, LogAction), ProcessControl's logs while its inspector's toggles are on, and a sequence's injection or chain logging, is information: the toggle decides whether it's made, and the level whether it's shown.

Its methods are marked to hide in the Console's stack, as the Console's Strip Logging Callstack hides them, and a double-click on a message it wrote opens the code that logged it, not this file.
