How far from its caster an ability's target may be: a capability an ability's component implements, as Cast Range does. The targeting tasks that search from their caster, the Creator Lab's bots and a game's own code ask an ability's reach through ForgeReach, never the component, so a reach of your own is asked as Cast Range is. A component that reaches enforces its reach itself, as Cast Range refuses a target beyond it.
