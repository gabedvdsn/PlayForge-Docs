Set Bonus: an effect its holder has while it has enough of a set's pieces equipped, as two pieces of a set giving fire resistance and four a flame aura. Each piece names its set by a tag and carries the set's bonuses; the holder's equipped pieces count each item once, and a bonus holds while they're as many as it needs, once for the holder however many pieces carry it. An item holds one for each of its set's bonuses.
