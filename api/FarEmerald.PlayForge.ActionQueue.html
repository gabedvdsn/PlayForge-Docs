An entity's queue of deferred actions, which its end of frame runs. Actions run by priority, higher first, and in the order queued within a priority; one queued as the queue runs takes its place by its priority in the same pass. Each is heard as it's queued, then once more as it's done with: run, dropped unrun, or failed.
