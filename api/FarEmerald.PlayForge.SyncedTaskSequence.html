Class SyncedTaskSequence

Namespace
FarEmerald.PlayForge
Assembly
FarEmerald.PlayForge.dll

Drives a list of synchronous sequence stages frame-by-frame. Uses the unified ISequenceTask interface (calls Step on each task). Designed to be called from a process's WhenUpdate.

Usage: var runner = TaskSequenceBuilder.Create("MyRunner") .Stage(s => s.Task(...)) .BuildSyncRunner();

// In WhenUpdate, a step of its clock, or of a time given: if (runner.Step(data)) relay.Terminate();
