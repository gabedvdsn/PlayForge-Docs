Class ProcessTaskUtil

Namespace
FarEmerald.PlayForge
Assembly
FarEmerald.PlayForge.dll

Extension methods an ability's tasks use on a data packet: the targeting packet under a tag (GetTargetingPacket, which interrupts a sequence's run where there's none, SetTargetingPacket and SetTargetingPackets), and the effects loaded under a tag, applied to a target with the magnitudes the caller set (TryApplyEffects) or read back (GetLoadedAssets). Its async loops, WhileAsync, DoWhileAsync and DoWhile, wait a tick between rounds.

GetTargetingPacket(ProcessDataPacket, Tag, out AbstractTargetingPacket, bool)

SetTargetingPackets(ProcessDataPacket, Tag, IEnumerable<ITarget>)

Files the packets of the targets a targeting task selected under query, in their order and in place of what was there, so the first is the primary. Each was set as the primary, so each replaced the last, and a task that selected several kept only the last of them: an Auto Target of every match kept the farthest.
