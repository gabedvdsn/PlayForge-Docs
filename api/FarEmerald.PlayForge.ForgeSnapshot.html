An entity at rest, as Capture(IGameplayAbilitySystem, ForgeAssetCatalog, IForgeEntityIds) takes it and Restore(IGameplayAbilitySystem, ForgeSnapshot, ForgeAssetCatalog, IForgeEntityIds) puts it back: its attributes' permanent commits, its levels, abilities, items and effects, its loose tags and its time scale. Plain serializable types, so a game writes a save where it likes, through JsonUtility or its own serializer. Assets are named by their IDs in a ForgeAssetCatalog and tags by name, which last across sessions as a reference doesn't.
