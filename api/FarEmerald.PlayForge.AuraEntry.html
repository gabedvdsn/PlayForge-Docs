An aura: an effect that holds on each it takes near its holder, and comes off as they leave, as Mekansm's or a captain's command aura does. An item's holds while it's equipped, an ability's while it's known, an effect's while it lasts on the one it's on, an entity's as it lives. It checks who's near every so often.
