Class GameRoot

Namespace
FarEmerald.PlayForge
Assembly
FarEmerald.PlayForge.dll

The game's own entity, a Mono hub every scene has one of, which ProcessControl hands any registration that names no handler. It runs as its Forge Project's Game Root entity: the project a scene's Bootstrapper plays, or else its own, or else the entity it names. It keeps through scene loads.
