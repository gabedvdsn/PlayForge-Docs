How a process starts and what follows its run: SelfTerminating starts running and ends as its run is done, as a projectile; RunThenWait starts running and waits when its run is done, to run again, as an ability; RequiresControl starts waiting and runs only when told, as an ability on a key; and Synchronous starts running with no run to await, stepped at its timing for as long as it lasts, as a health bar.
