Several numbers joined as one: each member is a scaler or a kind of number, and says how it joins the others. Members that add are added up; that sum is multiplied by each member that multiplies and divided by each that divides; then each flat bonus is added on. So (5 + Caster's Strength) × 2 + 3 is one number, a wind-up's 1.7 ÷ Caster's Attack Speed another, and a curse's 5 + what its worker answers is one magnitude.

A member that overrides gives the group's value alone. Where several override, OverrideMemberCollisionPolicy picks among them: the highest, the lowest, their average, the first or the last; Ignore sets them aside, and the other members join as they would without them.

Each member reads in the number's own context, so a member that is a kind reads all the field's context gives, and a member that is a scaler evaluates against the effect, or against the carrier the context fills where there's no effect. Joining its members allocates nothing.

It reads its members alone, so it has no values per level. With no members, or none that holds a kind, it is no kind at all (IsEmpty): its field reads its number, as a field with no kind does. It read values per level of its own, which its inspector hid.
