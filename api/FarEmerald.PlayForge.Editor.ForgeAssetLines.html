Class ForgeAssetLines

Namespace
FarEmerald.PlayForge.Editor
Assembly
FarEmerald.PlayForge.Editor.dll

One line for each asset, which its inspector's header and The Forge's list show: an ability's numbers by level, then its costs and cooldown, as "-450/-600/-750 Health; 280/420/680 Mana; 70/60/50 s"; an item's what it changes while equipped and the ability it grants, as "+20 Armor; Blink"; an entity's first attributes as it starts and its abilities, as "Health 500, Mana 300, Armor 5; Fireball, Blink"; an effect's first impact by level, as its Levels section reads it. Numbers that read what an editor can't give, as the target, are marked with a *.
