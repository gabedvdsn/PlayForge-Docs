A value through ordered stages as it lands. An effect names one as its impact's calculation, as an Unreal effect names its execution calculation, so each hit goes through the stages a project writes once: the caster's bonuses, those that read the target, a critical roll, the target's reductions, a barrier; and what comes out lands. A new item that changes every hit is a stage, not an edit to each attack. Generic: the value is any number an impact lands with, a blow, a heal, a drain.

It isn't a Scaler asset. A scaler is a number worked out from its context, read wherever a number is; a pipeline transforms a value it's given, once, as it lands, with both sides known, and its stages can do what a number can't: roll once for the hit and keep it, route a part of it into a barrier, say what each did.

It runs for what an impact commits: an instant impact's hit, each tick of a periodic one. A lasting impact's value is read again as its attribute changes, so nothing runs it.
