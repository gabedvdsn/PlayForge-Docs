Class ForgeRenames

Namespace
FarEmerald.PlayForge.Editor
Assembly
FarEmerald.PlayForge.Editor.dll

Renames an asset as its inspector does, from The Forge or an asset's header: a PlayForge asset's name, with the tag its name gives, as one Undo step; a Scaler asset's scaler and a Requirement template's requirements, whose names its lists show; and for an asset with no name of its own, as a Value Pipeline, its file alone. The file takes the name, with its type's prefix and suffix from Project Settings, leaving out its spaces as a new asset's file does, and follows the name back through Undo and Redo. A file that is its asset's only name keeps the spaces, and its rename Unity doesn't undo.
