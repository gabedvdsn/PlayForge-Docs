Class ForgeRandom

Namespace

FarEmerald.PlayForge.dll

The random numbers PlayForge's runtime draws: Unity's, unless Use(IForgeRandom) puts another source in, as SeededRandom. The runtime drew from UnityEngine.Random in five files, so a roll could be repeated only by seeding the whole game's random numbers.
