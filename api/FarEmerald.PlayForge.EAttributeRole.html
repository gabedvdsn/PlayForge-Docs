What an attribute is, which sets how bonuses to it add up and how a number reads it by default, as how several effects' Damage Amplification adds up and how an attack's scaler reads it. An effect's impact can add up its own way, and a number can read it its own way.

Guide: Attributes

public enum EAttributeRole

Fields

Value = 0

A value, as Health or Strength: bonuses add and multiply as each effect says; a number reads it as it is.

BonusShare = 1

A share more, as Damage Amplification at 0.2 for 20%: bonuses add, 0.2 and 0.3 making 0.5; a number reads it as a multiplier, 1 + x, 1.5.

Multiplier = 2

A factor, as Damage Dealt at 1: bonuses add and multiply as each effect says; a number reads it as it is.

Resistance = 3

A share taken off, or a chance, as Damage Resistance at 0.3: bonuses stack with diminishing returns, each on what's left, 1 − (1 − x)(1 − v), so two of 30% make 51% and none takes it past 1; a number reads what's left, 1 − x.

Barrier = 4

A barrier, as a shield before Health: it absorbs for the attribute it names, each workable loss to that one taken from it first, and it can decay, by a rate or with the effect that gave it.
