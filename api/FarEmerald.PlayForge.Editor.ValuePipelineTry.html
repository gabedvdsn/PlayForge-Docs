A Value Pipeline tried in the editor: a value put through its stages at each level of a range, against the stand-ins a Scaler asset's try reads against, a caster's and a target's attributes, typed or filled from an entity, and the values a caller sets. Each chance a stage rolls comes up where it can, or misses where it can, as ChancesComeUp says, so a read gives the same each time. A Block or Evade stage rolls first, as it does as an effect lands, and one that comes up stops the hit before the pipeline runs: nothing of it lands.

No effect is behind a try, so a stage that reads the hit's carrier reads none, and what an Absorb stage soaks comes off no one. A pipeline's try, from For(ValuePipeline), is kept for the session with Keep(), and never written into the asset.
