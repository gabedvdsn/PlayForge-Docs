Namespace
FarEmerald.PlayForge.Editor

FarEmerald.PlayForge.Editor.dll

A [SerializeReference] field of an abstract type: Unity's field, its label in the label column, the kind it holds named in its box, which opens Unity's searchable dropdown of the kinds it can hold; then the kind's own fields, each Unity's, indented under it. A pick makes a new object of the kind for each selected asset, by the kind's constructor so its initializers run, as one Undo step; drawing writes nothing.

Every element of a list shares one drawer, so each field keeps its state in its own elements. The drawer kept the last element's fields and kind in fields of its own, so an edit to one element could fill another with its fields. It drew a button that opened a list in tinted boxes, and the kind's fields in a box with an orange left border.
