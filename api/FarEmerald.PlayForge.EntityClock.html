Class EntityClock

Namespace
FarEmerald.PlayForge
Assembly
FarEmerald.PlayForge.dll

An entity's own time: the game's, as ForgeTime reads it, scaled by the entity's TimeScale: the scale code sets, as a hit-stop's, times the one its Time Scale attribute gives, as a slow's or a haste's, so the two compose. The entity's effects tick by it, its cooldowns among them, and so do its abilities' sequences and waits. Every entity ran on Unity's one clock, so nothing could slow one entity and not the rest. A scale of 0 holds the entity's time still; it isn't a pause, which ProcessControl's is, and processes keep their own bookkeeping on the game's clock. It's a clock as any other is, so a sequence that isn't an ability's runs on an entity's time with its packet's Clock set to it.
