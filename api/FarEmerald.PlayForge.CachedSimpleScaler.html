Class CachedSimpleScaler

Namespace
FarEmerald.PlayForge

Simple cached scaler based on the owning system's relative level. Has no attribute dependencies, so RegulateContactWith is a no-op (inherited from base). Returns the same scalar on both Current and Base sides — the blueprint will project whichever slot it needs.
