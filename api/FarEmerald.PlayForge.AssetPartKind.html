A part of an effect, an ability or an item on the caster or the target, found by a tag: a Poison effect's stacks, how many Fire effects are on the target, what every Burn there has dealt, the time left on a shield, an ability's level or whether it's cooling down, how many potions are in a stack, whether a ring is equipped. An effect matches by its asset tag, a context tag or a tag it grants; an ability or an item by its asset tag or a context tag; a tag under the one given matches too.

Where several match, Among says how they read as one: added up, the first, the highest or the lowest. A count reads 0 where none matches; any other part reads Default. A true-or-false part reads 1 or 0, so added up it's how many are so. An effect's Worker Value asks that effect's workers for a key (INumberWorker), about that application of it, and counts only the effects whose workers answer.
