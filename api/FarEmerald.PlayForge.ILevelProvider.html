Interface ILevelProvider

Namespace
FarEmerald.PlayForge
Assembly
FarEmerald.PlayForge.dll

Interface for assets that can provide level information to linked effects. Implemented by Ability and EntityIdentity to support "Lock to Source" level mode.

When a GameplayEffect is linked to an ILevelProvider, the effect's modifiers can derive their MaxLevel from the provider, ensuring consistent scaling.

Common use cases:

  • Ability Cost effect linked to its parent Ability
  • Ability Cooldown effect linked to its parent Ability
  • Entity-specific effects linked to EntityIdentity
