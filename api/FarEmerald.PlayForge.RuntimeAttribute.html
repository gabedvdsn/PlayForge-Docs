An attribute made in code, with no asset behind it: a name, an abbreviation and a description where it's given them, and textures AddTexture adds. AttributeRegistry.GetByName makes one for a name it doesn't know, where it's asked to, and an entity's attribute system takes one with ProvideAttribute(attribute, value).
