Class RuntimeGameplayAbilitySystem

Namespace
FarEmerald.PlayForge
Assembly
FarEmerald.PlayForge.dll

Runtime (non-MonoBehaviour) version of GameplayAbilitySystem. Instantiated at runtime as a plain class. Derives from LazyRuntimeProcess and implements the same IGameplayAbilitySystem interface as the MonoBehaviour version. What makes it a GAS lives in FarEmerald.PlayForge.GASCore, which it builds in its constructor and forwards to.

Usage: var gas = new RuntimeGameplayAbilitySystem(entityData); var relay = ProcessControl.Register(gas).With(dataPacket).Run().Relay;

Face(ITarget, float, float)

Turns the entity to face a target, which it follows as it moves, flat, at degreesPerSecond of its own time, 0 at once, until it faces it within within degrees. Another order replaces the turn; its death and StopTurning() end it. A turner of the game's own on its object, an IForgeTurner, takes each step where it has one; otherwise its facing is set. The entity itself, or a target with no place, turns nothing.
