Class ForgeValidator

Namespace
FarEmerald.PlayForge.Editor
Assembly
FarEmerald.PlayForge.Editor.dll

PlayForge's one validator. It runs every ForgeValidationRule on each PlayForge asset in the project and keeps what they find, which the Problems view lists and an inspector's header counts. It follows the project, so nothing polls: an edit checks its asset again, an import checks what it brought, and a deleted asset has every asset checked again, since another may have read it. In batch mode, LogAll() writes each problem to the Console. Validate All checked four things, flagged every effect with no workers, and showed 15 problems in a dialog.
