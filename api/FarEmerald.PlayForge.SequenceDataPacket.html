Class SequenceDataPacket

Namespace
FarEmerald.PlayForge

FarEmerald.PlayForge.dll

Extended ProcessDataPacket for TaskSequence execution. Provides direct access to sequence, stage, and chain control. All TaskSequence builder methods use this type for delegates.
