Interface IForgeMover

Namespace
FarEmerald.PlayForge
Assembly
FarEmerald.PlayForge.dll

A game's own mover, as the Creator Lab's units are, which PlayForge's movement tasks tell what they do: a Dash holds it while it moves its entity, and a Blink stops it after it puts its entity elsewhere, so it drops the path it was on. A component on the entity's object that implements it hears; an entity without one moves as the task puts it.
