Per-attribute runtime state under the two-kind impact model:

  • Modifiers (transient, derived) — registered via RegisterModifier(IAttributeImpactCarrier, IReadOnlyList<IAttributeImpacter>, IReadOnlyDictionary<IAttribute, CachedAttributeValue>) while their carrier lives, re-evaluated on every Recompute(IReadOnlyDictionary<IAttribute, CachedAttributeValue>), reversed exactly by UnregisterModifier(IAttributeImpactCarrier, IReadOnlyDictionary<IAttribute, CachedAttributeValue>).
  • Commits (permanent) — applied via CommitImpact(IAttributeImpactCarrier, IReadOnlyList<IAttributeImpacter>, IReadOnlyDictionary<IAttribute, CachedAttributeValue>); the post-bounds delta is recorded per retention group in FarEmerald.PlayForge.CachedAttributeValue.committedByGroup and NEVER reversed.

The formula (EFFECT_PIPELINE.md §2.1): ActiveValue = ConstrainValue( Override( FlatBonus( Multiply( Add( root ) ) ) + Σ committedByGroup ) ). Committed history lands where it was measured, after the % modifiers, so they don't scale it: 50 base × 1.5 aura + 10 tome = 85, and a 30 hit under the aura takes 30.

Reproducibility invariant: ActiveValue is always exactly what Recompute(IReadOnlyDictionary<IAttribute, CachedAttributeValue>) produces from current state — every mutation path ends in a recompute. There is no second bookkeeping system to drift.

CommitImpact(IAttributeImpactCarrier, IReadOnlyList<IAttributeImpacter>, IReadOnlyDictionary<IAttribute, CachedAttributeValue>)

Apply the given impacters as a PERMANENT commit. Each impacter runs as a sequential mini-step against the live value (op → bounds → rounding), and the post-constraint delta it produced is recorded into its retention group's committed history. A final Recompute(IReadOnlyDictionary<IAttribute, CachedAttributeValue>) then rebuilds ActiveValue canonically (committed history lands after the modifiers, where it was measured).

Commits are never reversed. There is deliberately no rollback path.
