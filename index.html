PlayForge

PlayForge is a gameplay framework for Unity 6, modelled on Unreal's Gameplay Ability System. Every ability, effect, attribute, tag and item is an asset you build in the inspector, and one hub on each entity runs them all.

Start here

Getting Started sets PlayForge up in a project, makes an entity, and gives it an ability that changes an attribute through an effect.
