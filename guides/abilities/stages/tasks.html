Tasks

A stage's Tasks are its work, such as Apply Effects, Delay or Run Sequence.

To add a task:

  1. Click the list's +. It adds an empty task.
  2. Pick a kind for it from the searchable picker, in which each task sits under its category (see Built-in tasks).

A task's numbers, as Delay's milliseconds and Channel's duration, are numbers that can scale by level. They're read as the task runs, at its ability's level. A stage that holds a critical task is critical.

Your own tasks in the picker

A task of your own names its submenu with [ForgeMenu("Effects", Description = "...")].

  • A slash nests one submenu in another.
  • A class's path holds for those made from it.
  • A task that names no submenu sits after the submenus.
  • A task's Description is what the picker's Context says while it's highlighted.

Run Sequence

Run Sequence runs the sequence a static method makes. You pick it in Sequence by name, from a searchable dropdown of the project's [TaskSequenceMethod] methods; where more than one class holds them, each class's sit under its name.

For an ability built in code, it runs a fresh run of the sequence its Definition describes, which TaskSequenceBuilder makes.

Its Clock picks the clock that sequence runs by. The ability's other tasks keep the caster's.

Option Clock
None The sequence's own, or the caster's.
Caster's The caster's.
Game's The game's.
Unscaled Runs while the game is paused.
Scaled A pace of its own.
