Abilities

An Ability asset describes one thing an entity can do, such as a fireball, a dash or a heal. An entity is anything that runs a gameplay ability system (GAS), such as the player or an enemy. An entity learns an ability from its Entity asset's Starting Abilities, from an equipped Item, or from code (AbilitySystemComponent.GiveAbility). It keeps the ability until the ability is removed.

Each time the ability activates, the GAS checks that it may run, lets a targeting task pick a target, then runs the ability's stages of tasks. The ability's cost and cooldown are gameplay effects, assets that change an entity, which it applies to its caster. Abilities run as processes under ProcessControl, so the scene needs one.

Tags are names, such as State.Stunned, that an entity carries and that requirements check. Each asset stores a tag made from its Name: Fire Ball gives Ability.FireBall. The entity carries this tag while it has the ability, and keeps the ability's level under it. Each section below matches the inspector section of the same name.

The inspector's header shows the ability's one line, as The Forge's Summary column does: each effect it applies, by its first impact across its levels, then its costs and its cooldown, as "-450/-600/-750 Health; 280/420/680 Mana; 70/60/50 s". A number that reads what the editor can't give it, as the target, is marked *.

In this guide

  • Identity: Name: the ability's display name.
  • Leveling: An ability has its own level on each entity that learns it, kept under the ability's asset tag.
  • Tags: Context Tags describe the ability, such as Spell or Melee.
  • Activation: This section is how the ability starts.
  • Stages: This section is what the ability does once it has started.
  • Requirements: Requirements are what an activation must pass.
  • Components: An ability's components are features it carries, each a class with hooks into its life, added with the list's +.
  • Workers: Workers are reusable behaviours, picked from a list, that react to what happens to an entity.
  • Local Data: Local Data is a list of named values stored on the asset.
  • Used By: The PlayForge assets that refer to this ability, each with its type icon, such as an entity that starts with it, an item that grants it, or a cost linked to it.
  • Built-in kinds: The kinds PlayForge ships for this guide's pickers, each with its menu and what it does, as its picker says.
