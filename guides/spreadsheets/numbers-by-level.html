Numbers by level

A sheet of numbers by level has a row for each number whose kind is a Table or By Level (Scalers). It holds the numbers of every asset, and of each Scaler asset, whose table its fields share:

Asset Tag Name Field Kind Level 1 Level 2 Level 3
Effect.LagunaBlade Laguna Blade Impact Specification › Magnitude Table -450 -600 -750
AttributeSet.Hero Hero Attributes › Health › Base Table 500 560 620
Column What it holds
Asset Tag, Name The asset the number is in. A row read back finds its asset by them (Reading a sheet back).
Field The number's place in the asset, its parts named as the inspector names them.
Kind The number's kind, Table or By Level.
Level 1, Level 2 and on What the number reads at each level.

In Field, a list's element is named by the attribute it names, as an attribute set's Health. An element that names no attribute is named by its place from 1, as Additional Impacts 2.

The levels hold what the number reads at each level: its values combined with its number, as its field says. So a table of 450, 600 and 750, read times -1, is -450, -600 and -750. Reading a row back sets the values so the number reads what the row says.

A number that reads its number alone has no row. Neither has a number of another kind, as × Attribute.
