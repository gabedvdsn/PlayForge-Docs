Tags

The Tags section sets what the effect grants its target while it's on, and which other effects it removes, purges or blocks.

Burning's Tags section.

Property Description
Granted Tags Applied to the target while the effect is active. An Instant effect grants them only for the moment it applies.
Granted Abilities Given to the target as the effect lands, each at the level of what applied it, and taken back as it comes off.
Context Tags Describe the effect, such as Fire. They are not applied to the entity.
Removes Effects Tagged Makes the effect a cleanse.
Purges Makes the effect a purge, by the project's purge levels (Purging).
Blocks Effects Tagged Makes the effect an immunity.

A change of the target's sides while the effect lasts is a Side Change component (Side Change).

A granted ability that's running as the effect comes off is interrupted. An ability the target can't take, such as one it knows already when duplicates aren't allowed, isn't lent, so the target keeps its own as the effect comes off.

An Instant effect lends no abilities, as it's never on the target.

Each change the effect makes carries its context tags and its origin's context tags, and workers can filter by them.

As a cleanse lands, every other effect on the target tagged with one of its tags, or a child of one, comes off at the next tick, as a removed effect does. An effect counts as tagged by its asset tag, a context tag or a tag it grants.

For example, Status.Debuff takes off Status.Debuff.Poison and Status.Debuff.Burn, and State.Burning takes off whatever grants it.

As a purge lands, the effects on the target its strength reaches, of the kinds it names and applied by whom it says, come off.

While an immunity is on the target and its ongoing requirements hold, an effect tagged with one of its tags, or a child of one, can't land. Tags match the same way as for a cleanse, and applying a blocked effect returns false.

An immunity leaves the effects already on the target. Add the same tags to Removes Effects Tagged to clear them as it lands.
