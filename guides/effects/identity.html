Identity

  • Name: the effect's display name. It also gives the asset tag, so renaming the effect changes its tag. Update anything that names the old tag.

  • Description: free text for your UI.

  • Asset Tag: read-only, made from the Name: punctuation is dropped, and each word is capitalised and joined. The tag is stored when you edit the Name. If the stored tag differs from the one the Name gives, it shows in warning text with an Update button that stores the new one.

    The effect system finds an effect by this tag when it is applied again or removed, whoever applied it. While a Durational or Infinite effect is active, its target carries the tag. Cooldowns work this way: an ability's Cooldown check looks for the cooldown effect's tag on the caster.

  • Visibility: a tag your UI can read to decide whether to show the effect, such as Always Visible or Not Visible. The Forge lists it. The runtime doesn't act on it.

  • Textures: icons, each paired with a tag. The texture tagged Primary is the effect's icon. Without one, the first texture is used.

  • Inherit From Origin: its icon is its origin's, the ability, item or entity that applied it: the origin's texture under Origin Texture, a tag, Primary to start, which shows under it. Where the origin has none under that tag, the effect's own stands. A spec reads it, spec.GetIcon(), as the Demo's bar and the Additional Content's status bar do; an origin holds textures through IHasTextures, as abilities, items, effects, entities and both hubs do.
