Leveling

An effect has no level of its own. At runtime it takes the level of its origin. Its scalers use that level to pick per-level values, such as 20/30/40/50 damage at levels 1 to 4. A scaler is a value source, such as a table with one value per level. A level provider is the asset whose level range an effect is authored for, normally its origin.

  • Link Mode: Standalone (default): the effect takes the level of what applies it, as a note says. Linked To Provider takes the range from a level provider.
  • Level Provider, while linked: the asset the range comes from, an Entity, Ability, Effect, Item or Attribute Set. Right-click the field to pick from one type. A link that would make a loop is refused, with an error in the Console. While no provider is set, a warning says the effect takes the level of what applies it. Starting Level and Max Level show the provider's range, read-only.
  • Link Contained Effects, while linked, links every contained effect (see Impact) to this effect's provider, so their per-level values follow its range. Unlink Contained Effects removes the links that point at it. Each asks first, and one Undo takes it back.

The link serves the inspector: a scaler set to Lock To Level Provider shows one value per level of the provider. An effect field in another inspector, such as an ability's Cost, says how the effect takes its levels, and its Link links the effect to that asset.
