Which phase each system steps in. A GAS hub steps at UpdateAndLate: GASCore.Tick() in Update, its end of frame in LateUpdate.

// The handler is an IGameplayProcessHandler, as an entity's GAS is in the full package
ProcessControl.Register(process).HandledBy(handler).With(data).Run(out ProcessRelay relay);

relay.Pause();       // Waiting at once, out of the steps
relay.Unpause();     // Running again
relay.Terminate();   // ended, and cleaned up
await relay.WhenTerminated();

The relay is the handle on a registered process. It holds the process's state and how long it has lived, and it's how you act on the process.

A mono process's relay reaches its children too. Processes on child GameObjects pause and end with it, unless told not to.

Instantiators

A mono process's object comes from an instantiator, an AbstractMonoProcessInstantiator. An instantiator works as a pool does: it hands out an idle object, and takes it back as the process ends.

  • A registration can give an instantiator of its own with .InstantiatedBy(pool). It goes ahead of the handler's instantiator and the object's own.
  • With no instantiator, the object is cloned, and destroyed as its process ends.

An object whose process has ended is no longer IsInitialized, so a pool's object can run again.
