A number field in your own code

A field of your own is one line, and a float converts to it:

[Tooltip("How far it reaches")]
[NumberContext(NumberReads.Level | NumberReads.Caster, Unit = "m")]
[NumberMin(0)]
public ScalableFloat Range = 20f;
  • Read it with Range.Evaluate(context), with a NumberContext built Of what the code has: an effect's spec, an activation's data, a worker's context, an entity, a cue or a process. Range.Evaluate(context, this) also hands the field's object over, which is what Relative to a Field reads; a field read that way declares NumberReads.Owner, or NumberReads.All, and its kind menu then offers that kind.
  • [Tooltip] shows on the field's name.
  • [NumberMin(0)], [NumberMax(10)] and [NumberRange(0, 1)] limit the constant typed in the inspector, and a range sets it on a slider. On a field whose unit is "%" the limit is in what the field stores, so [NumberRange(0, 1)] is 0% to 100%, and a whole-number field takes the whole numbers inside the limits. They limit the constant alone: a number of another kind is worked out as the game runs, so where what it reads must stay inside limits, give it the Clamped kind or clamp what the code reads.
  • In a kind of your own, as an ability task, a targeting task or a scaler, [ShownWhen(nameof(UsePhysics))] shows a field only while a toggle of the same object is on, and [ShownWhen(nameof(Mode), (int)EMode.Area)] only while an enum is one of the values, as a targeting task's Detection Layers show under Use Physics. A task reads its numbers with Read(number, data), at its ability's level.
  • Every kind of your own, a task, a worker, a component, a cue, a kind of number or a condition, takes [ForgeMenu("Path/Sub", Name = "...", Description = "...")]: its picker files it under the submenus its path names, a slash nesting them; Name replaces its class's name in the picker and in its field; and Description is what the picker's Context says while it's highlighted. A path holds for the classes made from the one that names it, and [ForgeMenu("")] puts a kind at the top whatever its base names.
  • Unity's own [Min] and [Range] don't work on a number field: Unity gives the field to that attribute's drawer, which draws "Use Range with float or int" where the number was. As scripts load, the console names each number field that has one, with the attribute to use in its place.
