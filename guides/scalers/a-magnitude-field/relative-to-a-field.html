Relative to a Field

Relative to a Field reads another number field of the same object, picked from a menu of them.

Property Description
Field The other number field of the same object it reads.

The field's number joins the other field's as Combine says. A Clamped scaler's Max can be 2 × its Min, and a stack bound's Max its Min + 3.

  • The other field is read in the same context, so a relative Max follows a Min that scales by level.
  • A field offers this kind where its code hands its object over as it reads (A number field in your own code).
  • A scaler's own numbers read the scaler as their object. So a Clamped's Max Value can be Relative to a Field, 2 × its Min Value, whatever field the Clamped is in.
