Limits

The limits apply to the constant alone.

  • On a field whose unit is "%", the limit is in what the field stores, so [NumberRange(0, 1)] is 0% to 100%.
  • A whole-number field takes the whole numbers inside the limits.
  • A number of another kind is worked out as the game runs. Where what it reads must stay inside limits, give it the Clamped kind, or clamp what the code reads.
Note

Unity's own [Min] and [Range] don't work on a number field. Unity gives the field to that attribute's drawer, which draws "Use Range with float or int" where the number was. As scripts load, the console names each number field that has one, with the attribute to use in its place.
