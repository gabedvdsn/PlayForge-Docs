Built-in kinds

The kinds PlayForge ships for this guide's pickers, each with its menu and what it does, as its picker says. A project's own kinds join them in the same pickers.

Scalers

Kind Menu What it does
AttributeBackedScaler — An attribute of the caster or the target, times a number for each level.
CachedAttributeBackedScaler Scaler An attribute's value through a curve by level, kept as the attribute changes.
CachedAttributeScaler Scaler Another attribute's value, kept as it changes.
CachedScalerGroup Scaler Several kept numbers joined as one.
CachedSimpleScaler — A number for each level, for an attribute set's start.
ConstantScaler Scaler One number, whatever the level.
EffectStacksScaler Effect The effect's stack count.
ItemStacksScaler Item The stack count of the item that applied the effect.
RandomizedScaler Scaler A number for each level, with random variance.
ScalerGroup — Several numbers joined as one.
SharedCachedScaler — A shared Scaler asset's number, for an attribute set.
SharedScaler — A shared Scaler asset's number, so one edit reaches every field that uses it.
SimpleScaler — A number for each level.

Number kinds

Kind Menu What it does
AssetPartKind — A part of an effect, an ability or an item on the caster or the target, found by a tag, as its stacks.
ClampedScaler Scaler A number kept between a floor and a ceiling.
ConditionalScaler Scaler One number where a condition holds, and another where it doesn't.
GroupImpactKind — One retention group's part of an attribute.
LocalDataKind — A value kept in Local Data, under a key.
RelativeToFieldKind — Another number field of the same object, times or plus a number.
SetByCallerScaler — A value code passes in under a tag as it applies the effect or activates the ability.
StackingCurveKind Scaler A count, as stacks, through a stacking curve, then a number added.
ThresholdScaler Scaler A number for each tier of levels.
TrackedImpactKind Effect What an effect has dealt: its last impact, its total, or how many.
WorkerNumberKind — A value a worker answers under a key.

Variances

Kind Menu What it does
FlatVariance (Flat) — Up or down by an amount, as 5 for a hit of 20 landing from 15 to 25.
MultiplierVariance (Multiplier) — The value times a multiplier between its Min and its Max, as 0.9 to 1.1.
PercentageVariance (Percentage) — Up or down by a share of the value, as 0.1 for 10% either way.

Scaler behaviours

Kind Menu What it does
AttenuateScalerBehaviour — Turns the number into a factor: as it is, one plus it, or one minus it.

Conditions

Kind Menu What it does
AllCondition Logic Holds where every one of its conditions holds.
AlwaysCondition — Always holds.
AnyCondition Logic Holds where any one of its conditions holds.
AttributeCondition — Compares an attribute of the caster or the target with a number.
ChanceCondition — Holds on a roll of its chance.
CompareCondition — Compares one number with another.
LevelCondition — Compares the level with a number.
NeverCondition — Never holds.
NotCondition Logic Holds where its condition doesn't.
TagCondition — Holds where the caster or the target has a tag.
