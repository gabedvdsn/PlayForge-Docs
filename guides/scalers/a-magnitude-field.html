A magnitude field

A magnitude field, such as an effect's Magnitude or Duration, is a number field. It's a ScalableFloat, or a ScalableInt for a whole number.

How number.Evaluate(NumberContext.Of(x)) reaches a value, from the constant check to the combine.

The field's row shows its name, then its kind, then what it reads, then its field menu. The field menu opens as wide as its items.

The sections below cover where number fields appear, how a field picks its kind, each kind in turn, and the field's tools.

In this section

  • Where number fields appear: Every number an asset authors is a number field, read at the level of what holds it.
  • The kind menu: The kind menu says where a field's number comes from.
  • Combine and Rounding: A kind other than Constant shows a one-line summary of what the field reads under its row, as "0.3 × Target's Health (base)".
  • Constant: A Constant field reads its number, with its unit beside it, as Tick Every's "1 s".
  • Table: A Table reads one value for each level, exactly.
  • By Level: A By Level field reads its values spread over a level range, as points on a curve.
  • Shared: A Shared field reads a Scaler asset, one scaler that many fields can use.
  • × Attribute: × Attribute reads an attribute of the caster or the target.
  • Set By Caller: Set By Caller reads a value the code passes in.
  • Asset Part: Asset Part finds effects, abilities or items on the caster or the target by a tag, and reads a part of them.
  • Group: A Group joins several numbers as one.
  • Group Impact: Group Impact reads one retention group's part of an attribute on the caster or the target.
  • Local Data: Local Data reads the number under a Key in Local Data.
  • Relative to a Field: Relative to a Field reads another number field of the same object, picked from a menu of them.
  • Worker: Worker asks workers for a number under a Key.
  • Clamped: A Clamped keeps a number within bounds.
  • Conditional: A Conditional reads one number where a condition holds, and another where it doesn't.
  • Fixed Value: A Fixed Value is one number, whatever the level.
  • Randomized: A Randomized scaler rolls a random value.
  • Stacking Curve: Stacking Curve turns a Count, as an item's stacks or an attribute, into its number by a Curve and its Coefficient, a.
  • Threshold: A Threshold steps at thresholds: it reads one value for each tier of levels.
  • Effect Stacks: Effect Stacks reads the stack count of the effect's own container.
  • Tracked Impact: Tracked Impact reads what an effect has dealt.
  • Item Stacks: Item Stacks reads the stack count of the item that applied the effect (Items).
  • Retention groups: An attribute's value is the sum of its retention groups' parts: the base its set gives, what items add in their group, and what a buff adds in its.
  • The field menu: The field menu holds a number field's tools.
  • Editing several assets: With more than one asset selected, the field edits each asset's own field.
