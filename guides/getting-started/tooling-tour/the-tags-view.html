The Tags view

The Forge's Tags view lists the project's tags, and what uses each.

The Forge's Tags view.

  • Open it with Tags, in The Forge's toolbar.
  • A context is a kind of tag, as Granted, Event, Impact Type or Local Data Key. A tag field's picker offers the kinds it takes.
  • A tag's Declared For declares it for contexts, so their fields' pickers offer it. A Tag Library asset (Create → PlayForge → Tag Library) keeps the declarations.
  • The view renames a tag, as F2 or a row's Rename… does, and the tags under its path with it, everywhere they're stored. An asset's own tag follows its asset's name instead.

The Editor Tools: The Tags view covers the view, and Tags covers tags, their contexts and the Tag Library.
