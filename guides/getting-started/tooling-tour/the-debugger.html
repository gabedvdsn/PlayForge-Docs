The Debugger

The Debugger shows the game as it plays, in four views the toolbar switches between.

The Debugger beside the Demo in play.

  • Open it from Window → PlayForge → Debugger.
  • Entities lists every entity, of either kind, with its attributes, effects, abilities, tags and combat log. A foot row under each table acts on the entity: set values, apply or remove effects, grant and activate abilities, add tags.
  • Processes lists every process with its state and how long its steps take. It pauses, resumes or terminates the one selected.
  • Tags shows every tag the entities hold, as a tree, and who holds the one selected.
  • Timeline records each run of an ability, stage by stage, each effect's time on the shelf, and the refusals, and draws them over the last seconds.

The Editor Tools: The Debugger covers each view in depth.
