Getting Started

PlayForge is a Gameplay Ability System (GAS) framework for Unity 6+: entities own attributes, gameplay effects modify them, abilities orchestrate effects through staged task pipelines, and tags glue everything together for requirements, filtering and UI.

In this guide

  • Requirements: Unity 6.0+ (built and tested on 6000.0) From the Asset Store, PlayForge installs in Assets/Plugins/PlayForge, and your Forge Projects go in Assets/PlayForge, so the two never share a folder.
  • The pieces in one paragraph: An EntityIdentity asset configures an entity: its AttributeSet (attributes with starting Current/Base values, clamping, regulation), starting Abilities, starting Items, tags and level range.
  • Quickstart: a damage ability in ~10 minutes: Everything below can be done from Window → PlayForge → The Forge (its Create menu), or via the Create → PlayForge asset menu, which lists the Forge Project, then the assets The Forge lists, in its order, then the…
  • Tooling tour: The Creator Lab (Window → PlayForge → Creator Lab) — a space to try the project's own assets in: put units and test dummies down, drop effects, abilities and items on them, and read any asset's numbers level by…
  • Logging: All the runtime says goes through ForgeLog, controlled in Preferences → PlayForge → Logging (Verbose / Info / Warning / Error / None).
  • Profiling: PlayForge's work shows in Unity's Profiler under its own markers, in the Scripts category (ForgeProfiler)
