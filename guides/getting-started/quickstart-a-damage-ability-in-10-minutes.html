Quickstart: a damage ability in ~10 minutes

This quickstart builds a damage ability, Fireball, from its attribute up to a scene that runs it.

You can make each asset below from Window → PlayForge → The Forge, with its Create menu. You can also use the Create → PlayForge asset menu, which lists the Forge Project, then the assets The Forge lists, in its order, then the numbers, rules and the Tag Library.

  1. Attribute: create an Attribute asset named "Health".
  2. AttributeSet: create a set, and add an element for Health:
    • Current/Base 100;
    • Overflow policy ZeroToBase, so Current can never exceed Base (pool-style).
  3. EntityIdentity: create one. Assign the AttributeSet, and set its level range.
  4. GameplayEffect "Fireball Damage": set its Duration policy to Instant, and give it an impact:
    • Attribute = Health, Operation = Add, Magnitude = -30;
    • or attach a scaler for per-level values, like −20/−30/−40/−50.
  5. Ability "Fireball":
    • Add a targeting task, for example SelectGasTargetTask.
    • Add one stage, with an ApplyEffectsAbilityTask referencing the damage effect.
    • Assign Cost and Cooldown effects, if you want them.
    • Set the level range, and link the damage effect's scaler with LockToLevelProvider.
  6. Scene:
    • Add a GameplayAbilitySystem to a GameObject, and assign the EntityIdentity.
    • Bring PlayForge up with a Bootstrapper: the prefab PlayForge makes in Assets/PlayForge/Bootstrap as your first Forge Project is made, or a GameObject with the component, naming the Forge Project the scene plays.
    • The Bootstrapper makes ProcessControl and the GameRoot, which runs as the project's Game Root entity.
    • Grant and activate the ability through the AbilitySystemComponent.

Instead of a GameObject, you can drive everything from code with RuntimeGameplayAbilitySystem, which needs none. ProcessControl.Register(gas).Run() starts it.

In this section

  • Code-driven abilities (sequences): For behaviour beyond declarative tasks, an ability runs a code-driven sequence.
  • Running a process or a sequence: You run a process or a sequence from code through ProcessControl.Register.
  • Time and random numbers: This section covers where PlayForge's time and random numbers come from, and the clocks an entity or a sequence runs by.
  • Tooltips: what does this ability do?: AbilityInspector.Build(ability) describes what an ability does, for a tooltip.
