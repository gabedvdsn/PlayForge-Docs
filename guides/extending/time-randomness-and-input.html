Time, randomness and input

PlayForge reads its time, its random numbers and its pointer through sources a game can replace, so a game can run it on a fixed step, repeat its rolls, or aim with a gamepad. This section covers the interfaces; Time, Input and Logging covers clocks, rolls and input in full.

  • IForgeClock: DeltaTime, UnscaledDeltaTime, FixedDeltaTime, Time, UnscaledTime, FrameCount, and FollowsTicks, true unless it runs while the game's time stands. ForgeTime.Use(clock) puts one in for the game and returns the one it replaced; null puts Unity's back. A run takes one of its own through its packet's Clock, a sequence through TaskSequenceBuilder.WithClock(clock).
  • IForgeRandom: Value, from 0 to 1, InsideUnitCircle and InsideUnitSphere. ForgeRandom.Use(source) puts one in and returns the one it replaced; SeededRandom(seed) is one of PlayForge's. The cues draw from their own, ForgeCues.Random.
  • IForgeInput: PointerPressed(int button) and TryGetPointerRay(out Ray ray) are required; PointerHeld, TryGetPointerPosition, ScrollDelta, KeyPressed and KeyHeld are optional. ForgeInput.Use(input) puts one in, and the click-targeting tasks and the sequence library's waits read ForgeInput.Current.
using FarEmerald.PlayForge;
using UnityEngine;

namespace MyGame
{
    // A pointer the game moves itself, as a gamepad's cursor
    public sealed class CursorInput : IForgeInput
    {
        public Camera Camera;
        public Vector2 Position;
        public bool PressedThisFrame;

        public bool PointerPressed(int button) => button == 0 && PressedThisFrame;

        public bool TryGetPointerRay(out Ray ray) => ForgeInput.TryAimThrough(Camera, Position, out ray);

        public bool TryGetPointerPosition(out Vector2 position)
        {
            position = Position;
            return true;
        }
    }
}

ForgeInput.Use(new CursorInput { Camera = Camera.main }) puts it in; the game sets Position as its cursor moves, and PressedThisFrame for the one frame of a press.
