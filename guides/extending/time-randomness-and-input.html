Time, randomness and input

PlayForge reads its time, its random numbers and its pointer through sources a game can replace, so a game can run it on a fixed step, repeat its rolls, or aim with a gamepad.

This section covers the interfaces; Time, Input and Logging covers clocks, rolls and input in full.

In this section

  • Clocks: A clock is where PlayForge reads its time, so a game can run it on a step of its own.
  • Random sources: A random source is where PlayForge draws its random numbers, so a test or a replay can repeat its rolls.
  • Input: An input source is where PlayForge reads the pointer, so a game can aim with a gamepad's cursor.
