Deferred actions

A deferred action is a piece of work queued to an entity that runs at its end of frame, by priority.

Deferred workers return them, and any code queues one with entity.GetActionQueue().Enqueue(action). This section covers writing one; Workers: The action queue covers when the queue runs and what it tells.

In this section

  • Writing an action: An action of a game's own does a piece of work at an entity's end of frame, as sending it an event once the frame's changes have run.
  • PlayForge's own actions: PlayForge's own actions are each usable from a game's code.
