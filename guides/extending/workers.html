Workers

A worker is a small rule that reacts to what happens: an attribute's change, a hit it deals, its tags, its frame's events, an effect's life.

An entity holds workers in a worker group, and an effect holds them in its Workers. This section covers writing each kind. Workers: The map maps when each runs and on whose system, and Workers: The action queue covers the queue its actions wait in.

Base Picked in Hooks
AbstractAttributeWorker, AbstractFocusedAttributeWorker a worker group's attribute workers Intercept, DeferredIntercept
AbstractImpactWorker, AbstractContextImpactWorker a worker group's impact workers ActivateInline, CreateDeferredActions
AbstractTagWorker a worker group's tag workers Activate, Tick, Resolve
AbstractAnalysisWorker a worker group's analysis workers Analyze
AbstractEffectWorker an effect's Workers OnEffectApplication, OnEffectTick, OnEffectRemoval, OnEffectImpact

A worker group (StandardWorkerGroup) sits on an attribute set, an Entity asset, a Forge Project's settings, an item, an ability and an effect (Workers: Where workers come from). Code gives an entity one with group.ProvideWorkersTo(entity), and takes it back with group.RemoveWorkersFrom(entity).

A deferred worker returns actions, IEnumerable<IRootAction>, which wait in its entity's action queue for its end of frame (Deferred actions). Return Array.Empty<IRootAction>() for none.

Each kind lists its own traps, and Traps, last in this section, lists those every worker shares.

In this section

  • Attribute workers: An attribute worker runs inside a change to one of its entity's attributes, where it can edit the change or queue actions.
  • Impact workers: An impact worker runs as a change its holder dealt lands on another's attribute, for the attribute it subscribes to.
  • Tag workers: A tag worker acts while its entity's tags meet its Tag Requirements.
  • Analysis workers: An analysis worker reads its entity's frame as it ends, after the tag workers.
  • Effect workers: An effect worker hears its effect's life: as it lands, as it lasts, as it comes off, and as a change it made lands.
  • A worker that answers a number: A worker of any kind can answer number fields of the Worker kind, under a key.
  • Traps: These traps apply to every kind of worker.
