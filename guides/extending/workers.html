Workers

A worker is a small rule an entity holds in a worker group, or an effect holds in its Workers, that reacts to what happens: an attribute's change, a hit it deals, its tags, its frame's events, an effect's life. This section covers writing each kind; Workers: The map maps when each runs and on whose system, and Workers: The action queue the queue its actions wait in.

Base Picked in Hooks
AbstractAttributeWorker, AbstractFocusedAttributeWorker a worker group's attribute workers Intercept, DeferredIntercept
AbstractImpactWorker, AbstractContextImpactWorker a worker group's impact workers ActivateInline, CreateDeferredActions
AbstractTagWorker a worker group's tag workers Activate, Tick, Resolve
AbstractAnalysisWorker a worker group's analysis workers Analyze
AbstractEffectWorker an effect's Workers OnEffectApplication, OnEffectTick, OnEffectRemoval, OnEffectImpact

A worker group (StandardWorkerGroup) sits on an attribute set, an Entity asset, a Forge Project's settings, an item, an ability and an effect (Workers: Where workers come from). Code gives an entity one with group.ProvideWorkersTo(entity) and takes it back with group.RemoveWorkersFrom(entity).

A deferred worker returns actions, IEnumerable<IRootAction>, which wait in its entity's action queue for its end of frame (Deferred actions). Return Array.Empty<IRootAction>() for none.

Attribute workers

An attribute worker runs inside a change to one of its entity's attributes. AbstractFocusedAttributeWorker watches one, its Target Attribute, and filters the changes it takes by its Timing (TimingConfig: Pre Change, Post Change or both), Sign Policy, Allow Self Modification, impact types and context tags, and registers itself; a worker of it overrides Execution and its hook:

  • EWorkerExecution.Inline: Intercept(WorkerContext ctx) runs inside the change. In Pre Change it edits ctx.Change.Value, and what it leaves is what commits.
  • EWorkerExecution.Deferred: DeferredIntercept(WorkerContext ctx) returns actions, which run at the end of frame.
  • EWorkerExecution.InlineAndDeferred: both.

WorkerContext holds System, the entity whose attribute changes; AttributeCache, its attributes' values as they stand; Change; FrameSummary; and ActionQueue. AbstractAttributeWorker itself leaves everything to the worker: Timing, PreValidateWorkFor(ChangeValue), a quick first test, ValidateWorkFor(WorkerContext), and RegisterWithHandler and DeRegisterFromHandler, which add it to the pre- and post-change handlers with handler.AddWorker(attribute, this) and take it off with RemoveWorker.

using System;
using FarEmerald.PlayForge;
using UnityEngine;

namespace MyGame
{
    [Serializable]
    [ForgeMenu(Description = "Keeps any one loss of its attribute to a share of the attribute's base, so no hit takes it all.")]
    public class CapLossWorker : AbstractFocusedAttributeWorker
    {
        [Tooltip("The most one loss takes, as a share of the attribute's base: 0.25 for a quarter")]
        [NumberRange(0f, 1f)] public ScalableFloat MostShare = 0.25f;

        public CapLossWorker()
        {
            TimingConfig = EChangeEventTiming.PreChange;
            SignPolicy = ESignPolicyExtended.Negative;
        }

        public override EWorkerExecution Execution => EWorkerExecution.Inline;

        public override void Intercept(WorkerContext ctx)
        {
            if (TargetAttribute == null || !ctx.AttributeCache.TryGetValue(TargetAttribute, out var cached)) return;
            var change = ctx.Change.Value;
            float most = cached.ActiveValue.BaseValue * (MostShare?.Evaluate(NumberContext.Of(in ctx)) ?? 1f);
            if (most <= 0f || change.CurrentValue >= -most) return;
            // The same change, its carrier and its workable mark kept, taking no more than the most
            ctx.Change.Value = new SourcedModifiedAttributeValue(change, -most, change.BaseValue, change.ImpactIsWorkable);
        }
    }
}
  • Edit a change by building it again from itself, as above. ChangeValue.Add, Multiply and Override mark the change workable whatever it was, so a system change they touch starts reaching impact workers and lifesteal (Workers: Workable and unworkable).
  • An inline worker never changes an attribute itself, which would run workers inside workers. It edits the change, or it's deferred.
  • AbstractRelativeAttributeWorker adds GetRelative(ctx), the value of the attribute it's relative to.

Impact workers

An impact worker runs as a change its holder dealt lands on another's attribute, for the attribute it subscribes to. It runs for the dealer: its context's System is its holder, the one who dealt the change, and the one hit is ImpactData.Target. ImpactWorkerContext holds System, ImpactData (Target, Attribute, SourcedModifier, RealImpact, OldValue), FrameSummary and ActionQueue.

AbstractImpactWorker's members:

  • PreValidateWorkFor(ImpactData), a quick first test, then ValidateWorkFor(ImpactData).
  • Execution: Deferred unless it says. A deferred one returns actions from CreateDeferredActions(ctx); an inline one acts in ActivateInline(ImpactData).
  • SubscribeToCache(ImpactWorkerCache) and UnsubscribeFromCache, which give it to the cache under an attribute with cache.ProvideWorker(attribute, this) and take it back with RemoveWorker.
  • OncePerHit: true runs it once for a hit however many of it its holder has, its project's and its own.
  • Accept Unworkable Impact (AcceptUnworkableImpact): off, it hears only workable changes.

AbstractContextImpactWorker does the validation and the subscription from its fields: Impacted Attribute, impact types, Impact Target, Impact Sign, Allow Self Impact, context tags, and a Work Attribute for its work. It starts narrow, Any Context Tag off and Impact Sign Positive, so it takes only gains carrying the context tags it names; a worker of it that means losses from anything says so in its constructor:

using System;
using System.Collections.Generic;
using FarEmerald.PlayForge;
using UnityEngine;

namespace MyGame
{
    [Serializable]
    [ForgeMenu(Description = "Gives its holder some of its Work Attribute for each point of loss it deals another, as rage.")]
    public class GainOnHitWorker : AbstractContextImpactWorker
    {
        [Tooltip("What its holder gains for each point of loss it deals")]
        public ScalableFloat PerPoint = 0.5f;

        public GainOnHitWorker()
        {
            AnyContextTag = true;
            ImpactSign = ESignPolicy.Negative;
        }

        public override IEnumerable<IRootAction> CreateDeferredActions(ImpactWorkerContext ctx)
        {
            // Its holder dealt the hit: the context's System
            var holder = ctx.System;
            if (WorkAttribute == null || holder == null || holder.IsDead) return Array.Empty<IRootAction>();
            float gain = -ctx.ImpactData.RealImpact.CurrentValue * (PerPoint?.Evaluate(NumberContext.Of(in ctx)) ?? 0f);
            if (gain <= 0f) return Array.Empty<IRootAction>();
            return new IRootAction[]
            {
                new ModifyAttributeAction(holder, WorkAttribute,
                    SourcedModifiedAttributeValue.GenerateSimple(holder, WorkAttribute, gain, 0f)),
            };
        }
    }
}

SourcedModifiedAttributeValue.GenerateSimple(source, attribute, current, base) makes a change of the source's own, a workable one. A change made for a worker is never built over the hit's carrier, ctx.ImpactData.SourcedModifier: that would count as the hit's effect again.

Tag workers

A tag worker acts while its entity's tags meet its Tag Requirements. Its hooks are handed the entity:

  • Activate(system), as its requirements come to be met, and Resolve(system), as they no longer are. Each runs as an action at the entity's end of frame, at ActionPriority.TagWorker.
  • Tick(system), at each end of frame while they hold, after the activations. Tick Pause (TickPause) is the frames between ticks, read at the entity's level: 0 ticks every frame, -1, as it starts, never. It counts frames, not seconds.
  • ValidateWorkFor(ITagHandler): whether its requirements are met, by default its packets' weights.
  • EvaluateEveryFrame: true has it asked in every end of frame, for a worker whose ValidateWorkFor reads more than tags; otherwise it's asked only in a frame the entity's tags changed.
using System;
using FarEmerald.PlayForge;
using UnityEngine;

namespace MyGame
{
    [Serializable]
    [ForgeMenu(Description = "Sends its entity an event as its tag requirements come to be met, and another as they stop.")]
    public class TagEventsWorker : AbstractTagWorker
    {
        [Tooltip("The event its entity is sent as its requirements come to be met")]
        [ForgeTagContext(ForgeContext.Event)]
        public Tag OnMet;

        [Tooltip("The event its entity is sent as they stop being met")]
        [ForgeTagContext(ForgeContext.Event)]
        public Tag OnLost;

        public override void Activate(IGameplayAbilitySystem system)
        {
            if (OnMet.IsValid) system?.SendGameplayEvent(OnMet);
        }

        public override void Resolve(IGameplayAbilitySystem system)
        {
            if (OnLost.IsValid) system?.SendGameplayEvent(OnLost);
        }
    }
}

The events feed the entity's abilities' triggers and their Wait For Event tasks. A tag worker is handed only its entity, and it's one object for every entity that holds it: what it keeps for one entity goes in an entity service or the entity's Local Data.

Analysis workers

An analysis worker reads its entity's frame as it ends, after the tag workers: Analyze(IGameplayAbilitySystem system, FrameSummary frameSummary) returns the actions it queues. The summary holds the frame's impacts, dealt and received (ImpactsDealt, ImpactsReceived, and by attribute, target and source), the effects applied and removed, the deaths, and the actions dropped and failed.

For a worker that fires once, the base keeps a mark in the entity's Local Data: HasTriggered(system), SetTriggered(system) and ResetTriggered(system), under its own key, MyKey. A revive calls Rearm(system), which resets it.

using System;
using System.Collections.Generic;
using FarEmerald.PlayForge;
using UnityEngine;

namespace MyGame
{
    [Serializable]
    [ForgeMenu(Description = "Applies an effect to its entity in a frame it deals enough hits to others.")]
    public class FlurryWorker : AbstractAnalysisWorker
    {
        [Tooltip("The losses it deals others in one frame that fire it")]
        [Min(1)] public int Hits = 3;

        [Tooltip("The effect its entity takes as it fires")]
        public GameplayEffect Effect;

        public override IEnumerable<IRootAction> Analyze(IGameplayAbilitySystem system, FrameSummary frameSummary)
        {
            if (Effect == null || system == null || frameSummary == null) return Array.Empty<IRootAction>();
            int dealt = 0;
            var impacts = frameSummary.ImpactsDealt;
            for (int i = 0; i < impacts.Count; i++)
            {
                var impact = impacts[i];
                // A workable loss to another: an entity's own changes are recorded as dealt to itself too
                if (impact.SourcedModifier.ImpactIsWorkable && impact.RealImpact.CurrentValue < 0f
                    && !ReferenceEquals(impact.Target, system)) dealt++;
            }
            if (dealt < Hits) return Array.Empty<IRootAction>();
            return new IRootAction[] { new ApplyEffectAction(system, Effect, IEffectOrigin.GenerateSourceDerivation(system)) };
        }
    }
}

Analyze runs at every end of frame of every entity that holds the worker. A method that yield returns makes an object each call, so one that usually returns nothing returns Array.Empty<IRootAction>() instead, as above.

Effect workers

An effect worker hears its effect's life. Each hook is handed an EffectWorkerContext and returns actions:

Hook Called System
OnEffectApplication(ctx) As the effect lands. The one it's on
OnEffectTick(ctx) Every frame a periodic effect lasts, with ExecuteTicks, the ticks that frame executes: most frames none. The one it's on
OnEffectRemoval(ctx) As it comes off. The one it's on
OnEffectImpact(ctx) As a change it made lands, with ImpactData. The dealer, its caster

The context also holds Carrier, the effect's application, with Spec the same as a GameplayEffectSpec; FrameSummary; ActionQueue; Impacts; and GetState<T>(this), what the worker keeps for this application.

using System;
using System.Collections.Generic;
using FarEmerald.PlayForge;
using UnityEngine;

namespace MyGame
{
    [Serializable]
    [ForgeMenu(Description = "Applies an effect from the caster as its effect comes off, once it has ticked enough.")]
    public class PayoffWorker : AbstractEffectWorker
    {
        [Tooltip("The effect the one it's on takes as it comes off, from its caster")]
        public GameplayEffect Payoff;

        [Tooltip("The ticks its effect must have executed")]
        [Min(1)] public int Ticks = 3;

        // What it counts for one application of its effect
        private sealed class Count
        {
            public int Ticks;
        }

        public override IEnumerable<IRootAction> OnEffectTick(EffectWorkerContext ctx)
        {
            if (ctx.ExecuteTicks > 0 && ctx.GetState<Count>(this) is { } count) count.Ticks += ctx.ExecuteTicks;
            return Array.Empty<IRootAction>();
        }

        public override IEnumerable<IRootAction> OnEffectRemoval(EffectWorkerContext ctx)
        {
            var target = ctx.Carrier?.GetTarget();
            var caster = ctx.Carrier?.GetOrigin()?.GetSource();
            if (Payoff == null || target == null || caster == null || target.IsDead
                || ctx.GetState<Count>(this) is not { } count || count.Ticks < Ticks) return Array.Empty<IRootAction>();
            return new IRootAction[] { new ApplyEffectAction(target, Payoff, IEffectOrigin.GenerateSourceDerivation(caster)) };
        }
    }
}

AbstractAccumulatingEffectWorker adds a running total of the effect's impacts, through GetAccumulationData(ctx), which a worker of it keeps; TargetAttributeThresholdEffectWorker queues the actions its OnThresholdMet(ctx) returns as its target's attribute meets a threshold.

A worker that answers a number

A worker of any kind that implements INumberWorker, bool TryGetNumber(Tag key, in NumberContext context, out float value), answers number fields of the Worker kind under a key (Scalers: Asking a worker).

Traps

  • An impact worker's System is the dealer, and an effect worker's OnEffectImpact runs on the dealer's side too (Workers: Traps).
  • OnEffectTick runs every frame of a periodic effect, not on each tick. Act where ExecuteTicks is above 0.
  • A deferred worker's actions wait for the end of frame, so what it reads as it builds them may have changed as they run. An action reads the state it acts on as it executes.
  • A worker is shared: a tag or analysis worker keeps nothing for one entity in its fields.
  • Allocation. Workers run in the frame's hot path; an attribute worker for every change. Hold back from new lists, closures and iterators in a hook that runs for every change, and return Array.Empty<IRootAction>() for nothing.
