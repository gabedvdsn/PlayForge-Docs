Tags in code

A game's code names tags for its kinds to read: a data key, an event, a state its components grant. This section covers what a kind of a game's own does with tags; Tags covers tags in full.

  • A tag field's picker offers the tags of the contexts its [ForgeTagContext(...)] names: PlayForge's (ForgeContext.Granted, ForgeContext.Event, ForgeContext.DataKey, ForgeContext.ImpactType, ForgeContext.ContextTag, ForgeContext.AssetTag and the rest) or a project's own, by name.
  • A tag written in code is Tag.GenerateAsUnique("State.Stunned"), the tag the editor's New Tag makes of the path. [ForgeTagExposed(context)] on a static Tag field or property offers it to the pickers of that context.
  • An event goes to an entity with entity.SendGameplayEvent(eventTag, data), which its abilities' triggers and Wait For Event tasks hear. A game's own events are tags of the Event context.
  • A tag's weight is entity.GetTagWeight(tag). An absent tag's weight is -1, so a test for one is > 0.
  • A tag is shown by its ToString(), its display name.
