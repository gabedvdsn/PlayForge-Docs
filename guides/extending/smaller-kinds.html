Smaller kinds

This section covers the smaller kinds a game picks in one field each: where an entity respawns, how charges come back, what a purge takes, how a modifier changes an effect, a Local Data value's type, and the clock a run takes.

Respawn places

A Respawn component's At is an AbstractRespawnPlace: Vector3? Where(EntityComponentContext context, Vector3? home), where the entity revives, handed where it stood as it registered; null, where it died. Describe() gives the component's line, as "at home".

using System;
using FarEmerald.PlayForge;
using UnityEngine;

namespace MyGame
{
    [Serializable]
    [ForgeMenu(Description = "A random point within a radius of where it registered.")]
    public class NearHomeRespawnPlace : AbstractRespawnPlace
    {
        [Tooltip("How far from home it may come back")]
        [Min(0f)] public float Radius = 3f;

        public override Vector3? Where(EntityComponentContext context, Vector3? home)
        {
            if (home == null) return null;
            var offset = ForgeRandom.InsideUnitCircle * Radius;
            return home.Value + new Vector3(offset.x, 0f, offset.y);
        }

        public override string Describe() => $"within {Radius:0.#} of home";
    }
}

Charge recharges

A Charges component's Recharge is an AbstractChargeRecharge: InHand(AbilityCharges charges), the charges in hand, by default its most less those cooling down; Spend(AbilityCharges charges, ProcessDataPacket data), as a charge is spent, by default starting one's cooldown; and CountsASingleCharge.

Purge filters

An effect's purge takes the effects its Filters let it, each an AbstractPurgeFilter: bool Takes(in PurgeContext ctx), with ctx.Container, the effect it might take; ctx.Purged, the entity it's on; and ctx.Purger (Effects: Purging).

Effect changes

A modifier's rule changes an effect it reaches through its Changes, each an AbstractEffectChange: Apply(EffectChanges changes, GameplayEffectSpec spec, EffectModifierRule rule) writes what it changes into changes, and Describe() gives its line (Effects: Modifiers).

Local Data values

A Local Data entry's value is a LocalDataValue, and one that holds a single value a LocalDataValue<T>, whose Value it holds. Read(in NumberContext) gives it as a packet takes it, and TryReadNumber(in NumberContext, out float) as a number reads it, where it's one. The Local Data list offers a kind with a constructor that takes nothing, named without "Local".

using System;
using FarEmerald.PlayForge;

namespace MyGame
{
    public enum EElement { None, Fire, Frost, Storm }

    [Serializable]
    [ForgeMenu(Name = "Element", Description = "One of the game's elements.")]
    public class LocalElement : LocalDataValue<EElement>
    {
    }
}

asset.TryGetLocalData(key, out DataWrapper entry) && entry.TryGet(out EElement element) reads it. An entry is the asset's own: a value changed at run time changes the asset, so Local Data is read, not written, as the game runs.

Clock choices

A Run Sequence task's or a Sequence cue's Clock is an AbstractClockChoice: IForgeClock ClockFor(ProcessDataPacket data), the clock a run on the packet takes, or null for the run's own. OwnersClock(data), protected, gives the clock of the entity the packet is for (Time, Input and Logging).

Stack behaviours

An effect's Stack Behaviours are AbstractStackingConfigs. A game can derive one, but its members work on the effect system's stacking containers, which this guide doesn't cover; Effects: Stacking (Stack Existing only) covers the built-in ones.
