The Creator Lab

The Creator Lab plays a project's assets on units of its own (The Creator Lab). This section covers driving its units the game's own way, through a driver.

A driver is an ILabUnitDriver: MoveTo(LabUnit unit, Vector3 point), Attack(LabUnit unit, LabUnit target), bool Cast(LabUnit unit, Ability ability, ProcessDataPacket data) and Stop(LabUnit unit). LabDriver, a ScriptableObject, implements each as the lab does unless overridden, and is made with Create → PlayForge → Lab Driver; a class of the game's own derives from it, and its asset is named on the lab's rules' Driver (The Creator Lab: Your unit).

using FarEmerald.PlayForge.Lab;
using UnityEngine;
using UnityEngine.AI;

namespace MyGame.Lab
{
    [CreateAssetMenu(menuName = "MyGame/NavMesh Lab Driver")]
    public class NavMeshLabDriver : LabDriver
    {
        public override void MoveTo(LabUnit unit, Vector3 point)
        {
            if (unit != null && unit.TryGetComponent(out NavMeshAgent agent) && agent.isOnNavMesh) agent.SetDestination(point);
            else base.MoveTo(unit, point);
        }

        public override void Stop(LabUnit unit)
        {
            if (unit != null && unit.TryGetComponent(out NavMeshAgent agent) && agent.isOnNavMesh) agent.ResetPath();
            base.Stop(unit);
        }
    }
}

The lab is its own assembly, FarEmerald.PlayForge.Lab, left out where the project defines PLAYFORGE_NO_LAB. A driver's assembly references it and carries the same constraint, !PLAYFORGE_NO_LAB among its Define Constraints, so it's left out with it.
