A game's own objects

PlayForge asks a game's own objects for a few things through interfaces: turning, moving, shaking the camera, and a pooled cue's comings and goings. This section covers each.

  • IForgeTurner, on an entity's object: Face(Vector3 direction, float degreesPerSecond, float deltaTime) takes each step of a turn PlayForge orders, as an ability's turn to face its target, in place of PlayForge setting the object's rotation. PlayForge reads how far is left from the object's rotation, so that's what the turner turns.
  • IForgeMover, on a caster's object: Hold(bool held) and Stop(), which the movement tasks, as Dash, call on the caster's own movement while they move it.
  • ICameraShaker: Shake(float strength, float duration), which the Camera Shake cue calls through ForgeCues.Shaker.
  • IPooledCue, on a pooled Prefab cue's prefab: Taken() as its pool hands it out, placed and active, and Returned() as it goes back (Cues: Pooling).
using FarEmerald.PlayForge;
using UnityEngine;

namespace MyGame
{
    // On an entity's object: turns it toward the direction PlayForge asks, at the speed it asks
    public sealed class SmoothTurner : MonoBehaviour, IForgeTurner
    {
        public void Face(Vector3 direction, float degreesPerSecond, float deltaTime)
        {
            direction.y = 0f;
            if (direction.sqrMagnitude < 0.0001f) return;
            var goal = Quaternion.LookRotation(direction);
            transform.rotation = degreesPerSecond <= 0f
                ? goal
                : Quaternion.RotateTowards(transform.rotation, goal, degreesPerSecond * deltaTime);
        }
    }
}

An animated character's turner sets its animator's turn here instead, and lets the animation turn the object.
