Sequence tasks, injections and stage policies

A task sequence runs stages of tasks, built in code with TaskSequenceBuilder (Task Sequences). This section covers what a game writes for one: a task, an injection that changes a run as it goes, a stage policy that says when a stage ends, and a method the inspector's sequence pickers list.

Tasks

ISequenceTask has four members, and two bases fill in what a task doesn't need:

Member Called
Prepare(SequenceDataPacket data) Before its first step or its run.
UniTask Execute(SequenceDataPacket data, CancellationToken token) Its run, in an async sequence.
bool Step(SequenceDataPacket data, float deltaTime) Each frame in a synced sequence, with the run's time; true ends it.
Clean(SequenceDataPacket data) After it ends, however it ended.
  • SequenceTaskBase: Execute is required, and its Step ends at once, so it does nothing in a synced sequence.
  • SyncSequenceTaskBase: Step is required, and its Execute steps it once a frame with the run's clock, holding while the run is paused, so one task serves both kinds.
using FarEmerald.PlayForge;
using UnityEngine;

namespace MyGame
{
    // Fades a canvas group to an alpha over a time, in an async sequence or a synced one
    public sealed class FadeTask : SyncSequenceTaskBase
    {
        private readonly CanvasGroup group;
        private readonly float to;
        private readonly float seconds;
        private float from;
        private float elapsed;

        public FadeTask(CanvasGroup group, float to, float seconds)
        {
            this.group = group;
            this.to = to;
            this.seconds = seconds;
        }

        public override void Prepare(SequenceDataPacket data)
        {
            from = group != null ? group.alpha : to;
            elapsed = 0f;
        }

        public override bool Step(SequenceDataPacket data, float deltaTime)
        {
            if (group == null) return true;
            elapsed += deltaTime;
            float t = seconds > 0f ? Mathf.Clamp01(elapsed / seconds) : 1f;
            group.alpha = Mathf.Lerp(from, to, t);
            return t >= 1f;
        }
    }

    public static class MenuSequences
    {
        public static TaskSequence FadeOut(CanvasGroup group) =>
            TaskSequenceBuilder.Create("Fade Out")
                .Stage(stage => stage.Task(new FadeTask(group, 0f, 0.4f)))
                .BuildSequence();
    }
}

MenuSequences.FadeOut(group).RegisterAndRun(SequenceDataPacket.Default()) runs it under ProcessControl. A task keeps its state in its own fields here, so one object serves one run at a time: a sequence that runs several at once builds a task for each, or keeps a run's state in its data packet.

A sequence the inspector lists

An ability's Run Sequence task and a Sequence cue pick a sequence from a dropdown of the project's methods marked [TaskSequenceMethod]: static, taking no parameters, and returning a TaskSequence, a TaskSequenceChain or a TaskSequenceDefinition. The dropdown names each by its [TaskSequenceMethod("...")] name, or its method's.

using System.Threading;
using FarEmerald.PlayForge;

namespace MyGame
{
    public static class GameSequences
    {
        [TaskSequenceMethod("Short Pause")]
        public static TaskSequence ShortPause() =>
            TaskSequenceBuilder.Create("Short Pause")
                .Stage(stage => stage.Task((CancellationToken token) => SequenceTaskLibrary.Delay(0.25f, token)))
                .BuildSequence();
    }
}

Injections

An injection changes a run as it goes: ISequenceInjection's one member, bool Apply(TaskSequenceRuntime runtime), acts on the run and says whether it took effect. It reaches a run through runtime.Inject(injection), sequence.Inject(injection) for every run of a sequence, the builder's InjectWhen, and an ability's Inject task, whose picker lists a [Serializable] injection with a constructor that takes nothing.

TaskSequenceRuntime gives an injection the run: Data, StageIndex, CurrentStage, IsRunning, IsPaused, Pause(), Resume() and Inject. The skips, jumps and interrupts themselves are the built-in injections' (SkipStageInjection, JumpToStageInjection, InterruptSequenceInjection and the rest), which an injection of a game's own composes:

using System;
using FarEmerald.PlayForge;
using UnityEngine;

namespace MyGame
{
    [Serializable]
    [ForgeMenu(Name = "Skip If Tagged", Description = "Skips the current stage where the caster carries a tag.")]
    public class SkipIfTaggedInjection : ISequenceInjection
    {
        [Tooltip("The tag on the caster that skips the stage")]
        [ForgeTagContext(ForgeContext.Granted)]
        public Tag Tag;

        public bool Apply(TaskSequenceRuntime runtime)
        {
            if (!Tag.IsValid || runtime?.Data is not AbilityDataPacket data) return false;
            var caster = data.EffectOrigin?.GetSource();
            if (caster == null || caster.GetTagWeight(Tag) <= 0) return false;
            // This injection passed the run's checks as it came in; the skip it composes is part of it
            return runtime.Inject(SkipStageInjection.Instance, overridePermission: true);
        }
    }
}
  • Permissions name injections by their exact type. A sequence or a stage that lists its allowed injections, AllowInjections(typeof(SkipIfTaggedInjection)), takes only those types, not types made from them.
  • A critical section takes only an interrupt unless its critical policy lists more.
  • An injection is one object every run shares; what it keeps for one run goes in the run's data.

Stage policies

A stage policy says when a stage ends: ISequenceStagePolicy's one member, UniTask AwaitCompletion(TaskSequenceRuntime runtime, SequenceStage stage, UniTask[] taskUnits, CancellationTokenSource stageCts), awaits the stage's running tasks as it sees fit. stage.WithPolicy(policy) gives a stage one. A policy of a game's own is handed a token source of its own, linked to the stage's, so cancelling it cuts off the stage's tasks and not the stage.

using System;
using System.Threading;
using Cysharp.Threading.Tasks;
using FarEmerald.PlayForge;

namespace MyGame
{
    // The stage ends as its first task finishes well; a task that throws ends it only where every task fails
    public sealed class FirstSuccessStagePolicy : ISequenceStagePolicy
    {
        public static readonly FirstSuccessStagePolicy Instance = new();

        public async UniTask AwaitCompletion(TaskSequenceRuntime runtime, SequenceStage stage, UniTask[] taskUnits,
            CancellationTokenSource stageCts)
        {
            if (taskUnits.Length == 0) return;
            int left = taskUnits.Length;
            bool succeeded = false;
            Exception firstError = null;
            var done = new UniTaskCompletionSource();

            foreach (var task in taskUnits) Watch(task).Forget();
            await done.Task;

            // The others are cut off as the stage ends
            stageCts.Cancel();
            if (!succeeded && firstError != null) throw firstError;

            async UniTaskVoid Watch(UniTask task)
            {
                try
                {
                    await task;
                    succeeded = true;
                    done.TrySetResult();
                    return;
                }
                catch (OperationCanceledException)
                {
                }
                catch (Exception error)
                {
                    firstError ??= error;
                }
                if (--left == 0) done.TrySetResult();
            }
        }
    }
}

TaskSequenceBuilder.Create("Search").Stage(stage => stage.Task(a).Task(b).WithPolicy(FirstSuccessStagePolicy.Instance)) gives a stage it. The Task Sequence Examples sample has another, a lead task the stage lasts as long as.

  • A synced runner can't run a policy of a game's own. It warns, and its stage waits for all its tasks.
  • An ability's stages take All or Any alone (Ability tasks).
  • A policy that returns ends the stage. One that waits on fewer than all its tasks cancels its source, so the rest stop with it.
