Built-in kinds

The kinds PlayForge ships for this guide's pickers, each with its menu and what it does, as its picker says. A project's own kinds join them in the same pickers.

Attribute workers

Kind Menu What it does
CantFallBelowAttributeWorker — Keeps its attribute from falling below a floor.
MathAttributeWorker — Changes each change to its attribute by another attribute.
ReturnDamageAttributeWorker — Sends a share of each loss back to the one who dealt it.

Impact workers

Kind Menu What it does
ImpactWorkerGroup — Several impact workers as one.
LifestealImpactWorker — Heals its holder a share of each loss it deals another.
RelativeOperationContextImpactWorker — Changes an attribute of its holder by a share of each impact.

Effect workers

Kind Menu What it does
AttributeChangeEffectWorker — Tells how far an attribute has moved since the effect began, for a number to read.
EffectWorkerGroup — Several effect workers as one.
ReviveOnRemovalEffectWorker — Revives the entity it's on as the effect ends, as a respawn timer.
ThresholdDebuggerEffectWorker — Logs as its target's attribute crosses a threshold, for debugging.

Analysis workers

Kind Menu What it does
DeathWatcherAnalysisWorker — Kills its entity as an attribute reaches its threshold, as Health reaching 0.
ThresholdAnalysisWorker — Applies effects and sends an event as an attribute crosses a threshold.

Actions

Kind Menu What it does
ApplyEffectAction — Deferred action to apply an effect.
DeathAction —
LambdaAction — Simple action that executes a lambda.
LogAction —
ModifyAttributeAction — Deferred action to modify an attribute.
RemoveEffectAction — Deferred action to remove an effect.
TagWorkerActivateAction — Deferred action to activate a tag worker.
TagWorkerResolveAction — Deferred action to resolve (deactivate) a tag worker.
