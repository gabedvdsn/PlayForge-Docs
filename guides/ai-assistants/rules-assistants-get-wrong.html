Rules assistants get wrong

  • Attribute is two types. PlayForge's attribute asset, FarEmerald.PlayForge.Attribute, shares its name with System.Attribute. A file with both using System; and using FarEmerald.PlayForge; can't name it bare. Alias it: using ForgeAttribute = FarEmerald.PlayForge.Attribute;.

  • Editor is a namespace. In code inside a namespace under FarEmerald.PlayForge, a bare Editor names FarEmerald.PlayForge.Editor. Write UnityEditor.Editor in full there.

  • An absent tag's weight is −1, not 0. TagCache.GetWeight returns −1 for a tag the entity hasn't. Test GetWeight(tag) > 0, or use TryGetWeight.

  • Components are read through Find<T>(). An asset's, a spec's or an entity's components are found by type: ability.Find<T>(), effect.Find<T>(), identity.Find<T>(). No property names a component.

  • Logs go through ForgeLog. ForgeLog.Info, Warning and Error are gated by ForgeLog.MinimumLevel, and code hears them through ForgeLog.Logged. Don't log PlayForge content with Debug.Log.

  • Input goes through ForgeInput. ForgeInput.Current reads the Input System or the Input Manager, whichever the project has, and a test puts in input of its own with ForgeInput.Use. Don't read UnityEngine.Input in content.

  • Time and chance go through ForgeTime and ForgeRandom, so a test can step the clock and script the rolls.

  • Current comes before Base. Wherever the two show together, in UI, logs and summaries, show Current first, then Base, as PlayForge's own tools do.

  • A process has one of four lifecycles:

    • SelfTerminating runs and ends, as a projectile;
    • RunThenWait runs, then waits to run again, as an ability;
    • RequiresControl waits until it's told to run;
    • Synchronous is stepped at its timing for as long as it lasts, as a health bar.

    There are no others.

  • ProcessControl steps every process. Register one with ProcessControl.Register(process)...Run(), and never call its update by hand (Processes).

  • An entity steps in LateUpdate. A Gameplay Ability System's ProcessTiming is UpdateAndLate. Code that sets it keeps Late in it, or the entity's end of frame never runs.

  • Wait with PlayForge's clock. In an ability task, await SequenceTaskLibrary.Delay(seconds, token) rather than UniTask.Delay, so a paused run stays paused, and pass the token, so an interrupt ends the task (Extending PlayForge: Ability tasks).

  • Show a tag by ToString(), its display name, not by its Name, which is its whole path.
