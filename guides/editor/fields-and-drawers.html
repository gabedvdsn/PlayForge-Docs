Fields and drawers

PlayForge's property drawers draw its fields wherever they're shown: in its own inspectors, in the Inspector of a component, and in an inspector of your own built with UI Toolkit. Most draw in UI Toolkit alone.

This section covers the kinds of field they make, then lists the drawers.

In this section

  • Asset fields: An asset field holds a PlayForge asset, a Value Pipeline, Crowd Control Rules or an Effect Modifier.
  • Kind fields: A kind field holds an object of one of several classes, such as an ability task, a worker, a component, a cue handler or a purge's filter.
  • Tag fields: A tag field shows its tag by its display name: its parents in secondary text and its leaf in strong text.
  • Lists: PlayForge's lists are Unity's reorderable lists.
  • PlayForge's dropdown: PlayForge's dropdown is the menu every PlayForge picker opens: a kind field's, the tag picker, an asset field's, Set Template..., a sequence reference's, and a number field's kind menu and field menu.
  • The drawers: PlayForge's drawers build on these base classes.
  • Asset reference drawers: These drawers draw a field that names an asset.
  • Ability drawers: These drawers draw an ability's parts: its behaviour, stages, tasks, checks and costs.
  • Effect drawers: These drawers draw an effect's parts, and an Effect Modifier's change.
  • Attribute and entity drawers: These drawers draw attributes, attribute set elements, roles and an entity's parts.
  • Worker and component drawers: These drawers draw workers, worker groups and components.
  • Tag drawers: These drawers draw tags, tag queries and tag requirements.
  • Other drawers: These drawers draw the rest of PlayForge's fields, and the classes with no drawer of their own.
