Import and Clear

A section's Import copies chosen fields into the asset from another, and its Clear resets the section. The asset menu's Import from Another Asset... imports the whole asset.

This section covers the Import window (ForgeImportWindow) and Clear (SectionClearUtility).

In this section

  • The Import window: The Import window copies chosen fields into an asset from another.
  • Clear: A section's Clear resets the section's fields at once, with no question.
