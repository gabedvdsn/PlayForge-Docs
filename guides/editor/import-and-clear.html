Import and Clear

A section's Import copies chosen fields into the asset from another, and its Clear resets the section; the asset menu's Import from Another Asset... imports the whole asset. This section covers the Import window (ForgeImportWindow) and Clear (SectionClearUtility).

The Import window

The window is titled for what it imports, as Import Leveling, names the asset it imports into, and goes in three steps:

  1. Choose a source: the type's Defaults, the assets Project Settings → PlayForge lists first for it, then the active project's other assets of the type, by name. The search finds a source by its name or its asset tag. A Workers section's Import lists any PlayForge asset with the same fields at the same paths, whatever its type, so an item's workers are a source for an ability's.
  2. Choose what to import: a row for each field that differs, checked, with its value now and the source's. Uncheck a field to leave it. A list is replaced, unless its row's Add is on, which adds the source's items after its own. Show matching lists the fields that are the same as well; otherwise a line names them.
  3. Import N Changes imports the checked fields as one Undo step, and closes the window.

Import from Another Asset... offers every field but those that make the asset itself: its name, description, textures and asset tag, its template, and its level link.

ForgeImportWindow.ShowFor(serializedObject, what, paths) opens the window for fields of your own choosing, and ForgeImportWindow.ShowForAsset(serializedObject) for a whole asset. Choose(source) picks the source, Changes lists what the import would change, each a ForgeImportWindow.Field, its Path, Label, whether it IsList, and whether it's included (Include) or added to (Append), and Import() imports them.

Clear

Clear sets each of the section's fields to a new asset's value and empties its lists, at once, with no question, as one Undo step. SectionClearUtility.Clear(serializedObject, sectionName, paths) does the same in code.
