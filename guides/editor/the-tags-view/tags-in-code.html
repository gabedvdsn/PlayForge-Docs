Tags in code

ForgeTagRegistry knows the tags in use.

Member Gives
GetAllTags() Every tag in use.
GetAllTagRecords() A record of each tag, each a ForgeTagRegistry.TagUsageRecord.
GetTagUsage(tag) One tag's record.
GetTagsForContext(...) The tags of a context.
GetAllContexts() The contexts, each a ForgeTagRegistry.TagContext.

A record holds each context's uses as a ForgeTagRegistry.ContextUsage, and each use as a ForgeTagRegistry.FieldUsageInfo: the asset and the field.

The registry reads the project again after an import of an .asset file, which TagRegistryAssetPostprocessor tells it. MarkDirty() and RefreshCache() ask it to read again.

A Tag Library's inspector (ForgeTagLibraryEditor) shows the shared header, then the library's entries and its contexts.
