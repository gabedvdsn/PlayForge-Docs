Menus and shortcuts

This section lists where each tool opens from.

Where Opens
Window → PlayForge → The Forge The Forge (The Forge)
Window → PlayForge → Debugger The Debugger (The Debugger)
Window → PlayForge → Problems The Problems view (The Problems view and validation)
Window → PlayForge → Creator Lab The Creator Lab, in a new scene, played (The Creator Lab)
Project Settings → PlayForge The settings a project shares (Preferences and Project Settings)
Preferences → PlayForge Your own preferences
Alt+Shift+F The Forge, with its search focused, from anywhere in the editor

The shortcut is PlayForge/The Forge in Unity's Shortcuts Manager, where it can be rebound.

Create → PlayForge, in the Project window, lists Forge Project; then Ability, Gameplay Effect, Item, Attribute, Attribute Set and Entity; then Scaler, Requirement Template, Value Pipeline, Effect Modifier, Crowd Control Rules, Tag Library and Cue Library; then Lab Rules and Lab Driver. Unity's Create menu makes the asset in the folder the Project window shows. The Forge's Create makes it where its project's settings put its type, named and tagged (New assets and presets).

The Forge's window menu, its tab's ⋮, holds Problems…, Project Settings…, Preferences…, Spreadsheets and Documentation. The Debugger's holds Samples a Second.
