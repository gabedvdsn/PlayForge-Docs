Menus and shortcuts

This section lists where each tool opens from: Unity's menus, a keyboard shortcut, and the tools' own window menus.

In this section

  • Opening the tools: Each PlayForge tool opens from Unity's Window menu, from a settings page, or with a shortcut.
  • The Create menu: Create → PlayForge, in the Project window, makes PlayForge's assets.
  • Window menus: Two tools add items to their window menu, the ⋮ on the window's tab.
