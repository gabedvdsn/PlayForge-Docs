New assets and presets

The Forge's Create makes an asset of any type it lists, blank or from a preset, ready to fill in. This section covers the New Asset window, what a new asset starts as, PlayForge's presets and a project's own templates.

Create

Create lists each type The Forge lists. A type with presets opens a submenu: Blank, then PlayForge's presets, then, after a line, the project's own templates. Each item opens the New Asset window (ForgeNewAssetWindow), titled for what it makes, as New Damage Effect:

  • Name: the new asset's name, which gives its asset tag. It starts as "New" and the preset's name or the type's.
  • Folder: the type's folder in the active project; Choose… picks another in Assets.
  • A line that says the file it will be, as File: IronSword.asset.
  • Create makes it, and The Forge shows it; Cancel closes the window. Enter and Escape do the same.

A field's New button opens the same window, its name starting as the holder's and the field's, as "Goblin Attribute Set" (Asset fields). ForgeNewAssetWindow.Show(type, onCreated) opens it from code, and CreateAsset() makes the asset as Create does.

What a new asset starts as

  1. A copy of its type's New Asset default, where Project Settings → PlayForge names one.
  2. Filled by its preset, or a copy of its template.
  3. Named, with the asset tag its name gives: the type, then the name's words capitalized and joined, its punctuation left out, as Item.IronSword for Iron Sword. An attribute takes no asset tag; a Scaler asset's name is its scaler's, and a Requirement Template's its requirements'.
  4. Saved in the folder, its file its name, with its spaces and any character a file can't have on any platform left out, and a number added where the folder has the name already.

The first asset made while the Unity project has no Forge Project makes one, named for the game, in a folder of its own under the PlayForge Folder.

PlayForge's presets

Create Makes
Gameplay Effect → Damage An instant −10 to the attribute playing the project's Health role, on those of other sides
Gameplay Effect → Damage over Time 5 seconds of −4 Health, a tick a second, on those of other sides. Applied again, it replaces the one before
Gameplay Effect → Buff +10 to an attribute you choose, for 10 seconds, on its own side. Applied again, it replaces the one before
Gameplay Effect → Debuff −10 to an attribute you choose, for 10 seconds, on those of other sides. Applied again, it replaces the one before
Gameplay Effect → Stun 1.5 seconds under the tag of the first rule in the project's Crowd Control that stops every ability, as Stunned
Gameplay Effect → Aura An infinite effect with an Aura component, which reaches its holder's allies within 5; the aura's effect is yours to choose
Item → On-Hit An item with an On Hit entry, which lands on the one hit; its effects are yours to name
Item → Active An item that grants an ability of its own, named for the item: one stage that applies its effects, and a Cost and a Cooldown effect, named for it and taking its levels
Ability → Passive An ability that activates as it's granted, with implicit targeting, so the effects its one stage applies land on its holder
Entity → Hero An entity with an attribute set of its own, named for it, as "Goblin Attributes" for Goblin: the attributes playing the project's roles, Health first, at 100, the rest at 0

An Active item's Cost and Cooldown are copies of the project's Cost Effect and Cooldown Effect where Project Settings → PlayForge names them, and otherwise a Cost of −10 to an attribute you choose and a Cooldown of 5 seconds. The assets a preset makes besides its own go in their types' folders, or in the folder the window names where that isn't the new asset's type's folder.

ForgePresets holds the presets in code: For(type) lists a type's, PlayForge's then the project's templates, each a ForgePreset: its Name in the menu, the Type it makes, the AssetName a new one starts as, its Description, and, for a template, the Template it copies; and Make(preset, name) makes an asset from one. As a preset fills a new asset it reaches a ForgePresetMaking: the new asset's Name and Folder, the Project and its Health attribute, Make<T> to make another asset it needs, and Then to act once the new asset is saved.

The project's templates

Project Settings → PlayForge → Templates lists assets of the project's own that a new asset can start as a copy of. Create lists each under its type, by its name, after PlayForge's presets. A new one is a plain copy that takes its own name and tag: it doesn't follow its template afterwards, as a child of Set Template... does (Templates).

An ability's Cost and Cooldown fields take the project's Cost Effect and Cooldown Effect from their right-click menu (Asset fields).
