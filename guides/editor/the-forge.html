The Forge

The Forge (TheForge) is PlayForge's main window: the active Forge Project's assets in a list, beside a detail pane that shows the one selected. This section covers its toolbar, its list, its detail pane, the asset menu and its keys. The Forge follows the project as assets are made, edited, moved and deleted, so it has no Refresh.

While the Unity project has no Forge Project, The Forge asks for the first in place of its list: Make your first Forge Project, a Name, and Create Forge Project (Forge Projects).

The toolbar

From left to right:

  • Back and Forward go over the assets the detail pane has shown, as a browser's do, up to 50 back. Going to an asset the list hides clears the search and turns its type's filter on.
  • The project menu, named for the active Forge Project, switches between the projects, the active one checked. No Project shows the assets in no project, where no project sits at the root of Assets. New Project… makes a project, and Show in Project selects the active one's asset. The menu reads No Project while none is active, and All Assets while the Unity project has none.
  • Create makes a new asset of any type The Forge lists (New assets and presets).
  • A filter for each PlayForge asset type, by its icon: Ability, Gameplay Effect, Item, Attribute, Attribute Set and Entity. On, it shows its type alone; off again, every type.
  • More holds the filters of the other types The Forge lists: Scaler Asset, Requirement Template, Value Pipeline, Effect Modifier and Crowd Control Rules. It shows the name of the one chosen.
  • Tags shows the project's tags in place of its assets (The Tags view).
  • The search shows the assets whose name, file name or asset tag holds its text.
  • The problem count, No problems or as 3 problems, opens the Problems view.
  • The help button (?), at the toolbar's end, opens this guide's section on The Forge on the documentation site.

The status bar under the list counts what it shows, of how many, in which project, and the problems, as "12 of 40 assets in Arena · 3 problems".

The list

Each column sorts by a click on its title, in natural order, so 9 comes before 10, then by name:

Column Shows
Name The asset's type icon and its name: its own, or its file's where it has none. Its tooltip is the asset's path
Type Its type
Asset Tag Its asset tag, for an ability, effect, item, entity or attribute set
Levels The levels it uses, as 1–5, for an asset with levels of its own
Summary Its one line, as its inspector's header shows it (The header); the whole line in its tooltip
(unnamed) A warning glyph where the validator finds problems in the asset, in the destructive color for an error; its tooltip says them

A click shows the asset in the detail pane. Several can be selected, to move, copy or trash together, and the first shows. A double click shows the asset in the Project window, and a right click opens the asset menu. The list's width, its columns' widths and the columns its header's menu hides are kept for each user, and its sort through a domain reload.

ForgeAssetLines.Of(asset) gives an asset's one line in code.

The detail pane

The detail pane shows the selected asset's Summary above its inspector. The summary holds the asset's description, where it has one; then a line for each section of its inspector, with the section's one-line summary, as Leveling Levels 1–5; for a Scaler asset, its Kind, what it Reads and its Used By; for a Requirement Template, what it Requires and what it Must Not Have; and last, Problems, what the validator finds. It follows the asset's edits.

The inspector under it is the asset's own, as the Inspector shows it (Inspectors). In The Forge, its header's Open in The Forge is Show in Project, and an ability's, effect's, item's, entity's, attribute's or attribute set's header shows the asset's file name under it, as the list shows its name alone.

The asset menu

The same actions open from a right-click on the list and from the ⋮ in an inspector's header, which adds the asset's own (The header):

  • Show in Project selects the asset in the Project window.
  • Open in a Window shows its inspector in a window of its own.
  • Rename… asks for its new name (Renaming, duplicating and deleting).
  • Duplicate makes a copy beside it, named as a copy, as "Fireball Copy", with the tag that name gives, and shows the copy.
  • Move to Project and Copy to Project move or copy every selected asset into another Forge Project, each into its type's folder there.
  • Move to Trash moves every selected asset to the trash, asking first.

The others act on the first selected asset.

The window menu

The window menu, the tab's ⋮, holds Problems…, Project Settings… and Preferences…, then Spreadsheets: Export Numbers…, Export Selected Numbers…, Export Item Stats…, Export Selected Item Stats… and Import… (Spreadsheets); then Documentation, which opens the documentation site in the browser: The Forge, this guide's section on it; The Editor Tools, this guide; All Guides; and API Reference, a page for each public type.

Keys

Key Does
Alt+Shift+F Opens The Forge with its search focused
Alt+Left, Alt+Right Back and Forward, except while a text field has the keyboard. The mouse's back and forward buttons do the same
F2 Renames the selected asset; in the Tags view, the selected tag
Delete, or Cmd+Backspace on a Mac Moves the selected assets to the trash, asking first
Enter, Escape In The Forge's dialogs, New, New Project and Rename, does the dialog's action, or cancels

In code, TheForge.OpenToAsset(asset) opens The Forge on an asset, its type's filter on and the asset selected, as an inspector's Open in The Forge does, and TheForge.ShowWindow() opens it as the menu does.
