Forge Projects

A Forge Project (ForgeProject) holds one game's PlayForge assets and its settings. The project is an asset, and the assets in its folder are the project's.

This section covers the project asset and its folder, which assets belong to which project, the active project, and moving assets between projects.

In this section

  • The project and its folder: A Forge Project lives in a folder of its own under the PlayForge Folder, with a folder inside for each type's assets.
  • The project's inspector: The project's inspector (ForgeProjectEditor) shows the project's fields, and a line in place of its catalog's entries.
  • Which assets belong to which: Each asset belongs to one project, or to none, by the folder it's in.
  • The active project: The active project is the one The Forge shows.
  • Moving and copying: Move to Project and Copy to Project, in the asset menu, put assets into another Forge Project.
