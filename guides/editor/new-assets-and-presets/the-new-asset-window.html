The New Asset window

The New Asset window (ForgeNewAssetWindow) names a new asset and says where it goes. It's titled for what it makes, such as New Damage Effect.

Control What it does
Name The new asset's name, which gives its asset tag. It starts as "New" and the preset's name or the type's.
Folder The type's folder in the active project. Choose… picks another in Assets.
File line Says the file it will be, such as File: IronSword.asset.
Create Makes the asset, and The Forge shows it. Enter does the same.
Cancel Closes the window. Escape does the same.

A field's New button opens the same window, its name starting as the holder's and the field's, such as "Goblin Attribute Set" (Asset fields).

In code, ForgeNewAssetWindow.Show(type, onCreated) opens the window, and CreateAsset() makes the asset as Create does.
