Sections

Under the header, an inspector's content is in sections. Each is drawn as Unity's foldout headers are: its arrow, its title, and, while it's collapsed, its one-line summary, such as Leveling Levels 1–5.

A click on a section's header opens or closes it. Each inspector type keeps which of its sections are open, so collapsing Tags on one ability keeps it collapsed on the next.

Section buttons

A section's buttons sit on its header and always show, where it has them.

Button What it does
Import Opens the Import window for the section's fields (Import and Clear).
Clear Resets the section's fields to a new asset's values, and empties its lists, at once. Undo takes it back.
Help (?) Opens the part of the asset's guide that covers the section, such as the Leveling section of Abilities: Leveling for an ability's Leveling.

The help buttons open PlayForge's documentation site in the browser. The site is built from the pages of the package's Documentation folder, which ship with it, to read offline.
