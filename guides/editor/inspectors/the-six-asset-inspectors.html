The six asset inspectors

Six inspectors edit PlayForge's main assets, with their sections in one order: Identity, Leveling and Tags, then the type's own, then Components, Workers and Local Data, and last Used By.

Inspector Sections
AbilityEditor Identity, Leveling, Tags, Activation, Stages, Requirements, Components, Workers, Local Data, Used By (Abilities)
GameplayEffectEditor Identity, Leveling, Tags, Duration, Impact, Requirements, Components, Workers, Local Data, Used By (Effects)
ItemEditor Identity, Leveling, Tags, Effects, Abilities, Components, Workers, Local Data, Used By (Items)
EntityIdentityEditor Identity, Leveling, Tags, Attributes, Abilities, Items, Death, Components, Workers, Local Data, Used By (Entities)
AttributeSetEditor Identity, Leveling, Attributes, Sub-Sets, Collision Settings, All Attributes, Workers, Local Data, Used By (Attribute Sets)
AttributeEditor Identity, Local Data, Used By (Attributes)

Each of the six edits several selected assets at once. The parts that hold each asset's own objects, such as an ability's components, ask you to select one asset instead.

Identity and Used By

Section What it holds
Identity The asset's Name and its Description. For an ability, effect, item, entity or attribute set, it also shows the asset tag its name gives, which can be selected and copied.
Used By The PlayForge assets whose data refers to the asset, each by its type icon and name, in name order. It follows the project as it changes, and a row opens its asset in The Forge.

Where the stored tag isn't the one the name gives, Identity shows the tag in warning text, with Update, which stores it.

Other marks

  • A template's child marks each field it overrides (Templates).
  • An ability's inspector shows the warnings and errors a component rule finds, under its Components list (A rule of your own).
