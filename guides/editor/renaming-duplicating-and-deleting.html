Renaming, duplicating and deleting

This section covers what a rename changes, and what Duplicate and Move to Trash do.

Renaming

An asset is renamed from the asset menu's Rename…, F2 on The Forge's list, or its inspector's Name. The Rename window (ForgeRenameWindow), titled for the asset's type, as Rename Ability, holds the asset's name selected, to type over; Rename, or Enter, renames it, and Cancel, or Escape, doesn't. A rename is one Undo step:

  • An ability, effect, item, entity or attribute set takes the name and the asset tag it gives. Every PlayForge asset that stored the old tag, as a requirement's tag query, a trigger or a filter, stores the new one, unless another asset still has the old tag as its own, as the one it was duplicated from.
  • An attribute takes the name. A Scaler asset's name goes to its scaler, and a Requirement Template's to its requirements, which the lists that offer them show.
  • The asset's file takes the name, its spaces and any character a file can't have left out, as a new asset's file does, with a number added where another file in its folder has the name. Undo and Redo bring the file back with the name.
  • An asset with no name of its own, as a Value Pipeline, is named by its file: renaming renames the file, its spaces kept, which Undo doesn't take back.

In an inspector, leaving the Name field of an ability, effect, item, entity or attribute set renames it this way, its file with it. Each one's tag comes from its own name, so a selection of several can't be renamed at once.

ForgeRenames renames in code: CanRename(asset), true for an asset that's its file's main asset; NameOf(asset), its name as The Forge lists it; and Rename(asset, name). ForgeRenameWindow.Show(asset) opens the window.

A tag is renamed in The Forge's Tags view (The Tags view).

Duplicating

Duplicate copies an asset beside it, named as a copy, as "Fireball Copy", with the tag that name gives. From The Forge's list, The Forge shows the copy; from an inspector's header, The Forge shows it where The Forge has the keyboard, and the Project window selects it otherwise.

Deleting

Move to Trash, or Delete on The Forge's list, asks once for every asset selected, naming the assets, prefabs and scenes that refer to any of them, up to eight, and counting the rest: their references will break. It then moves the assets to the trash, where they can be restored.
