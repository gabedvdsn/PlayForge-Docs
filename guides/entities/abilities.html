Abilities

The Abilities section sets the abilities the entity starts with, how many it can hold, and what its abilities do while another is busy.

Property Description
When Busy What one of the entity's abilities set to Entity's Policy does when it's asked to activate while another is busy:
Activate Anyway starts it at once.
Refuse starts it only when no ability under that choice is busy, and refuses it otherwise.
Queue (default) makes it wait in a queue while one is busy.
Targeting Yields On by default: an ability whose While Targeting is the entity's rule gives way, while it waits for its target, as another of the entity's abilities activates.
Starting Abilities Abilities the entity learns when its GAS initializes, each at its own Starting Level. Those set to Activate At Start then try to activate.
Max Abilities The most abilities the entity can hold, 99 by default. Its kind can make it a scaler, which changes the limit with the entity's level (Scalers).
Allow Duplicates Lets the entity hold the same ability more than once. Off by default.
Crowd Control The crowd control rules its abilities follow, such as a stun stopping every ability and Silenced stopping spells. Where it names none, the project's apply (Abilities: Requirements: Crowd Control).

Abilities explains each When Busy choice, and Targeting Yields. A runtime entity's identity names its crowd control rules too.
