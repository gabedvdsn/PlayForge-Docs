Stages

A pipeline's stages take the value in order, each giving what goes on to the next. Every stage has these fields:

Property Description
Label The name a breakdown gives it, as Amplification, Armor or Critical. Left empty, the breakdown says what the stage does.
Enabled Off, the value passes it by.

The stages PlayForge ships are below, and a project can write its own.

In this section

  • Multiply: A Multiply stage multiplies the value by a number read for the hit.
  • Add: An Add stage adds a number to the value's size.
  • Chance: A Chance stage multiplies the value by a number on a chance: a critical hit.
  • Clamp: A Clamp stage keeps the value's size between two numbers, its sign as it was.
  • Absorb: An Absorb stage takes a loss first from another attribute of the one hit, as a barrier or a shield takes a blow before health.
  • Block and Evade: A Block or Evade stage is a Chance, read as the effect lands, that stops it.
  • Execute: An Execute stage finishes off a hit's target, as Culling Blade.
  • Writing your own stage: A project writes its own stage by deriving from AbstractValueStage and overriding Apply(value, in run).
