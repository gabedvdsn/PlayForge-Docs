Crowd control

Crowd control stops abilities by the tags their caster carries. So no ability has to list Stunned among the tags it must not have.

A Crowd Control Rules asset, CrowdControlRules, holds its Rules. Make one with Create → PlayForge → Crowd Control Rules.

Each rule is a CrowdControlRule:

Property Description
Tag The tag its holder carries, as Stunned.
Stops What it stops, an ECrowdControlStops:
Every Ability, as a stun does.
Abilities Tagged: those whose asset tag or a context tag is one of its Ability Tags, or under one, as Silenced stops spells.
Ability Tags The tags Abilities Tagged looks for.

While the caster carries a rule's tag, or one under it:

  • an ability the rule stops is refused, as Crowd Control, the refusal's Rule naming the tag;
  • an ability the rule stops that's running is interrupted.

An ability's Ignores Crowd Control names the rules it ignores, by their tags. Each tag there also ignores the rules whose tags are under it.

An entity follows its own rules, its Crowd Control, or else its Forge Project's.

Method What it does
gas.GetCrowdControl() Gives the rules an entity follows.
rules.Stopping(ability, tags) Gives the first rule that stops an ability, or null.

Abilities: Requirements: Crowd Control has the rest.
