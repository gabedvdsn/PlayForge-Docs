What the registry reads

The editor's tag registry reads the project's tags as the editor loads. It reads them again after any .asset file is imported, moved or deleted (TagRegistryAssetPostprocessor).

It reads:

  • the code tags marked [ForgeTagExposed]: in Tags, in the player assemblies that reference PlayForge, and in each type given to RegisterContextDefaultSource;
  • every Tag Library;
  • every Tag field, list and array of the project's PlayForge assets, each use under its field's contexts.

The assets it reads are the project's abilities, effects, items, entities, attributes, attribute sets, Scaler assets, Requirement Templates, Value Pipelines, Effect Modifiers, Crowd Control Rules, Forge Projects and Creator Lab rules. It reads through their nested classes and [SerializeReference] fields, as their components and workers.

Note

A tag that only a Cue Library, a scene, a prefab or an asset of the project's own type holds is offered nowhere. It's offered once a PlayForge asset uses it, or a Tag Library declares it.
