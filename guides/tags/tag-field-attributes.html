Tag field attributes

The attributes a Tag field, or a list of tags, takes say what its tag field offers and does.

  • ForgeTagContext, as [ForgeTagContext(ForgeContext.Granted)] or [ForgeTagContext("Weather")], names the contexts the field takes, PlayForge's or the project's own, and makes the tags it holds of each. Its IncludeUniversal, true unless set, offers the Universal tags too, and its AllowCreate, true unless set, offers New Tag… and Make It a Child Of…. A field without one offers every tag.
  • ForgeTagNoCreate offers neither, as AllowCreate = false does.
  • ForgeTagExcludeUniversal leaves the Universal tags out, as IncludeUniversal = false does.
  • ForgeTagReadOnly shows the tag greyed, with no picker and no menu; code still sets it.
  • ForgeTagTooltip, as [ForgeTagTooltip("...")], gives the field its tooltip, in place of Unity's [Tooltip], which the field reads where it has none.
  • ForgeTagExposed goes on a static tag of code, not on an asset's field (Tags written in code).

ForgeTagDefault, ForgeTagRequired, ForgeTagPrefix, ForgeTagGroup, ForgeTagLockedCountAttribute and ForgeTagLockedIndicesAttribute are declared for a field as well, for a default tag, a tag the field must have, the prefixes it takes, a group of fields and a list's locked entries, but no drawer reads them, so they change nothing in the inspector; and ForgeTagDefault can't be written on a field at all, as a Tag can't be an attribute's argument. AvoidRequireTagGroupColor, on the requirement groups' fields, gives each a colour that no drawer reads.

using System;
using FarEmerald.PlayForge;
using UnityEngine;

// Refuses its ability while its caster is out of the weather it names
[Serializable]
public class NeedsWeatherAbilityComponent : AbstractAbilityComponent
{
    [Tooltip("The weather its caster must be under, or one beneath it")]
    [ForgeTagContext("Weather", AllowCreate = false)]
    [ForgeTagExcludeUniversal]
    public Tag Weather;

    public override string CanStart(AbilityComponentContext ctx)
    {
        var tags = ctx.Source?.GetTagCache();
        if (!Weather.IsValid || tags == null || tags.HasTag(Weather, ETagMatchMode.IncludeChildren)) return null;
        return $"Needs {Weather}";
    }
}
