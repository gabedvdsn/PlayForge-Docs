Requirements

Tag requirements are the tags an entity must have, and must not have, for an ability to activate and run, or for an effect to land, go on and come off. Each is a group, an AvoidRequireTagGroup, of two lists of tag queries:

  • RequireTags, the inspector's Requires: each must pass.
  • AvoidTags, its Must not have: none may pass.

A group passes when each query it requires passes and none it must not have does, so an empty group passes. Its Name, optional, tells it apart where it's imported.

Groups come in sets, each an AbstractTagRequirements, which says whether any of its groups asks anything (HasAnyRequirements), how many queries they hold (TotalRequirementCount) and whether one names a template (HasLinkedTemplates):

  • An effect has two EffectTagRequirements, one on its target and one on its source, each of three groups: Applying (ApplicationRequirements), which must pass for the effect to land; While on (OngoingRequirements), without which its ticks don't execute; and Removed by (RemovalRequirements), which takes it off once met, and asks nothing while empty (Effects: Requirements).
  • An ability has an AbilityTagRequirements: Caster (SourceRequirements), checked as it's asked to activate and again after targeting; While active (WhileActiveRequirements), the caster's for as long as it runs, checked as it's asked to activate and as the caster's tags change, which interrupts it as it fails; and Target (TargetRequirements), checked after targeting, where there's a target (Abilities: Requirements).
  • A targeting task has a lone group, its Requirements, which the target it takes must pass.

A set draws as a table, EffectTagRequirementsDrawer or AbilityTagRequirementsDrawer: a row for each group, with a cell for what it requires and a cell for what it must not have, each listing its tags or saying None. A lone group draws as a table of one row, AvoidRequireTagGroupDrawer. A cell opens its list under the table, with the group's Name, Template and Sync With Template, and closes it as it's pressed again.

What a row counts

A row reads its entity's tags as a list, each tag once, whatever its weight, so its numbers count tags: Greater Than 0 asks for the tag, and Greater Than 1 under Include Children for two different tags under it. The ability's While active row alone is read against the weights, as a Tag condition, the Tag Weight check and a tag worker are (Conditions and checks); to ask for stacks of one tag, as three grants of Combo.Points, use one of those.

Templates

A group's Template names a Requirement Template, RequirementTemplate (Create → PlayForge → Requirement Template): a group of its own, its Requirements, with a Description and a Category, a tag of the Requirement Category context, which groups templates. Its inspector, RequirementTemplateEditor, is the shared header over those fields. Sync With Template marks the group as following its template (ShouldSyncFromTemplate): TrySyncFromTemplate() copies the template's tags into a group that follows it, LinkToTemplate(template) links one and copies it, and UnlinkFromTemplate() lets it go, keeping its tags. A group checks its own tags.

In code

AddRequirement(tag, mode) and AddAvoidance(tag, mode) add a query of the tag's presence, and AddRequirementWithChildren(tag) and AddAvoidanceWithChildren(tag) one under Include Children; RemoveTag(tag) takes a tag's queries out, and Clear() all of them. Validate passes or fails a group against a cache or a list, as a query does, and ValidateDetailed says why, an AvoidRequireTagGroup.ValidationResult: its FailedRequirements, the queries it requires that failed; its TriggeredAvoidances, those it must not have that passed; and GetSummary(). GetAllReferencedTags() lists the tags a group names, Clone() copies it, and CopyFrom(group) takes another's.

using FarEmerald.PlayForge;

public static class Landing
{
    static readonly Tag Grounded = Tag.GenerateAsUnique("State.Grounded");
    static readonly Tag Disabled = Tag.GenerateAsUnique("State.Disabled");

    // Grounded, and nothing under State.Disabled
    static readonly AvoidRequireTagGroup CanLand = Make();

    static AvoidRequireTagGroup Make()
    {
        var group = new AvoidRequireTagGroup { Name = "Can Land" };
        group.AddRequirement(Grounded);
        group.AddAvoidanceWithChildren(Disabled);
        return group;
    }

    public static bool Allows(IGameplayAbilitySystem gas, out string why)
    {
        var result = CanLand.ValidateDetailed(gas.GetTagCache());
        why = result.IsValid ? null : result.GetSummary();
        return result.IsValid;
    }
}
