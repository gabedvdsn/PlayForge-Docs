Hearing tags change

An entity's TagCache tells each change to a tag's weight, to listeners on that tag and on the tags above it. A change is a TagChange: its Tag, and its weight Before and After, each 0 where the entity doesn't hold it, never −1; Added says the tag came, and Removed that it went.

  • tags.Listen(tag, onChange, kind) hears the tag, and every tag under its path, as a listener on Status hears Status.Burning, and gives a TagListener, whose Dispose() stops it. Its ETagChangeKind says what it hears: AddedOrRemoved, the default, a tag coming and going, or AnyCount, every change to a weight. A listener's Tag, Kind and Listening say what it hears and whether it still does.
  • tags.TagChanged hears every change to every tag.

A change made straight to the weights is told as it happens. A compile is told as it ends, with only what it changed, so a tag held throughout is told nothing, and a load's one compile tells what the load changed (Saving and Loading: What a load does). A listener that throws is logged, and stops neither the change nor the other listeners; one disposed while a change is told hears no more of it, and one added then hears the next. The entities' guide listens for a stun too (Entities: Tags).

using FarEmerald.PlayForge;
using UnityEngine;

public static class StatusDisplay
{
    // The tags New Tag makes of these paths
    static readonly Tag Stunned = Tag.GenerateAsUnique("State.Stunned");
    static readonly Tag Combo = Tag.GenerateAsUnique("Combo.Points");

    // Shows the icon while the entity holds State.Stunned or a tag under it; dispose the listener to stop
    public static TagListener ShowWhileStunned(IGameplayAbilitySystem gas, GameObject icon)
    {
        var tags = gas.GetTagCache();
        icon.SetActive(tags.HasTag(Stunned, ETagMatchMode.IncludeChildren));
        return tags.Listen(Stunned, _ => icon.SetActive(tags.HasTag(Stunned, ETagMatchMode.IncludeChildren)));
    }

    // Logs each change to the weight of Combo.Points, and of each tag under it
    public static TagListener LogCombo(IGameplayAbilitySystem gas) =>
        gas.GetTagCache().Listen(Combo, change => ForgeLog.Info($"{change.Tag}: {change.Before} -> {change.After}"),
            ETagChangeKind.AnyCount);
}
