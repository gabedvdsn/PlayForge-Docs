Tags written in code

Code makes a tag of a path with Tag.GenerateAsUnique, and offers it to the editor's pickers with [ForgeTagExposed].

  • Tag.GenerateAsUnique("State.Stunned") gives the unique tag of the path, the very tag New Tag makes of it, PlayForge's own among them: Tag.GenerateAsUnique("Died") is Tags.DIED. TagRegistry.FromSegments("State", "Stunned") makes the same tag of its parts.
  • Tag.Generate("State.Stunned"), and a string where a tag is asked for, as Tag tag = "State.Stunned";, give the plain tag of the path, which no unique tag equals: use them for tags that code alone makes and reads. Tag.Generate(name, displayName) makes a tag of a name and a display name of its own.
  • tag.Child("Burn"), TagRegistry.CreateChild(tag, "Burn"), GetParent() and GetAncestors() give plain tags of their paths, and so does GetRoot(), but of a root, which gives the tag itself.
  • TagRegistry.TagUtil makes the names: GenerateDeterministicTag(text, prefix, length) a unique tag's, the prefix and the text padded to the length, 32 to 64, by a SHA-256 hash of them, or cut short there; and GenerateUniqueRandomTag() a random tag no registered tag has. TagUtil.rngGenerationBufferSize, 64, is the length New Tag pads to.

Exposing them to the pickers

A static Tag field or property of the project's code, public or not, marked with ForgeTagExposed is offered by the pickers of the contexts it names, as [ForgeTagExposed(ForgeContext.Granted)], or, naming none, under Code, which the fields that name no context offer. A code tag not marked stays out of the pickers, so a project chooses which of its tags its designers see. The Tags view shows the contexts it's exposed for in Declared For, checked and locked, and can declare it for others besides.

The editor finds the marks once each domain reload, in the player assemblies that reference PlayForge, test assemblies left out. A tag written in an editor assembly reaches the pickers once its type is registered as the editor loads, as from an [InitializeOnLoad] class: ForgeTagRegistry.RegisterContextDefaultSource(typeof(EditorTags)), its marked members alone.

using FarEmerald.PlayForge;

public static class GameTags
{
    // The tag New Tag makes of State.Stunned, offered by the fields that take granted tags
    [ForgeTagExposed(ForgeContext.Granted)]
    public static readonly Tag Stunned = Tag.GenerateAsUnique("State.Stunned");

    // Offered by the project's own fields of its Weather context
    [ForgeTagExposed("Weather")]
    public static readonly Tag Rain = Tag.GenerateAsUnique("Weather.Rain");

    // Exposed for no context: under Code
    [ForgeTagExposed]
    public static Tag Cheats { get; } = Tag.GenerateAsUnique("Game.Cheats");

    // Not exposed: a key the game's code alone writes and reads
    public static readonly Tag Combo = Tag.Generate("Game.Combo");
}
