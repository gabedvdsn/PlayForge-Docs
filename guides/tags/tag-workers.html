Tag workers

A tag worker, AbstractTagWorker, acts while its entity's tags meet its requirements, as flames shown while Status.Burning weighs 3 or more. It's one of a Worker Group's Tag workers, its kind picked from the list, and its entity holds it as it holds the group (Workers: Where workers come from).

Its Tag Requirements (TagWorkerRequirements) list entries, each a TagWorkerRequirementPacket: a tag, that very tag; a policy, an ERequireAvoidPolicy, Require, which passes while the tag's weight is the entry's number or more, or Avoid, while it's below it; and that number, read at the entity's level. The requirements are met where every entry passes, and always where there are none. An absent tag weighs −1 here, as GetWeight gives it, so Require 1, and Require 0 too, ask for the tag, and Avoid 1 for its absence.

Its hooks, each a virtual no-op, run at its entity's end of frame:

  • Activate(system), once, as its requirements come to be met;
  • Tick(system) while they hold, after the activations: every frame at a Tick Pause of 0, every n + 1 frames at n, and never below 0, as at −1, the default; the pause is a number read at the entity's level;
  • Resolve(system), once, as they no longer hold, or at once where the worker is taken away while active, as its item is unequipped.

The entity reads its workers' requirements at the end of a frame in which its tags changed, a worker came or went, or its last reading started or stopped one, and queues each activation and resolution on its action queue, ahead of the ticks (Workers: The action queue). A worker whose ValidateWorkFor(handler) reads more than the tags, as an attribute, overrides EvaluateEveryFrame too, to be read every frame. TagWorkerActivateAction and TagWorkerResolveAction are the actions queued, at ActionPriority.TagWorker; the callbacks' OnTagWorkerActivated and OnTagWorkerResolved hear each, and the frame's FrameSummary keeps them. tags.IsWorkerActive(worker), ActiveWorkers and RegisteredWorkers say which run on an entity.

One worker serves every entity whose group holds it, each tracking it apart, so it keeps nothing of one entity in its fields; given by two sources, as two copies of an item, it runs once, and stays until the last takes it back. It draws as TagWorkerDrawer draws a worker of any kind, its Tag Requirements a list (TagWorkerRequirementsDrawer) of rows, each the tag, the policy and the number (TagWorkerRequirementPacketDrawer).

using System;
using FarEmerald.PlayForge;
using UnityEngine;

// Shows a child of its entity's object while the worker's Tag Requirements are met, as flames while
// Status.Burning weighs 3 or more
[Serializable]
public sealed class ShowWhileTagged : AbstractTagWorker
{
    [Tooltip("The child shown, by name, at any depth")]
    public string Child = "Flames";

    public override void Activate(IGameplayAbilitySystem system) => Show(system, true);

    public override void Resolve(IGameplayAbilitySystem system) => Show(system, false);

    private void Show(IGameplayAbilitySystem system, bool shown)
    {
        var body = system?.ToGASObject();
        if (body == null) return;
        foreach (var each in body.GetComponentsInChildren<Transform>(true))
            if (each.name == Child) each.gameObject.SetActive(shown);
    }
}
