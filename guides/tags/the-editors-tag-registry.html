The editor's tag registry

ForgeTagRegistry, in the editor, is what the tag pickers, the Tags view and New Tag know of the project's tags: each tag, and each use of it, by context. It reads, as the editor loads, and again after any .asset file is imported, moved or deleted (TagRegistryAssetPostprocessor):

  • the code tags marked [ForgeTagExposed]: in Tags, in the player assemblies that reference PlayForge, and in each type given to RegisterContextDefaultSource;
  • every Tag Library;
  • every Tag field, list and array of the project's abilities, effects, items, entities, attributes, attribute sets, Scaler assets, Requirement Templates, Value Pipelines, Effect Modifiers, Crowd Control Rules, Forge Projects and Creator Lab rules, through their nested classes and [SerializeReference] fields, as their components and workers, each use under its field's contexts.

A tag that only a Cue Library, a scene, a prefab or an asset of the project's own type holds is offered nowhere until a PlayForge asset uses it or a Tag Library declares it.

Tools of the project's own read it: GetAllTags(), GetTagsForContext(contexts, includeUniversal), GetTagUsage(tag), GetAllTagRecords(), GetAllContexts() and GetSystemDefaultTags(), the code tags; MarkDirty() has it read again as it's next asked, and RefreshCache() at once. A tag's uses are its ForgeTagRegistry.TagUsageRecord, by context, each a ForgeTagRegistry.ContextUsage of uses, each a ForgeTagRegistry.FieldUsageInfo: its Asset, its FieldPath, and whether it's code's (IsSystemDefault). A context is a ForgeTagRegistry.TagContext, whose ContextKey is Uncontextualized for a field that names none. The tag field tells the registry each pick, RegisterTagUsage and UnregisterTagUsage, so a picker knows it at once.
