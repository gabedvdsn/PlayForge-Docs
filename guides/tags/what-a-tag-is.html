What a tag is

A tag, a Tag, is a path of names joined by dots, parents first. Status.Debuff.Burn is under Status.Debuff, which is under Status, its root.

A Tag is a struct that an asset saves as two strings:

Field Description
Name What tells the tag apart. Two tags are equal, by == or Equals, exactly when their names are.
DisplayName How the tag reads. ToString() gives it, or the name where it has none, and PlayForge's windows show a tag this way.

A tag is of one of three makes:

Make Where it comes from Its name Its display name
Unique New Tag makes one (New Tag). PlayForge's own tags are unique (PlayForge's own tags). Its path, padded to 64 characters by a hash of it, as Status.Debuff.BurnQx3… Its path
An asset's own tag The asset's Name gives it, as Ability.FireBall for an ability named Fire Ball (Abilities: Identity). Its whole path Its leaf, FireBall
Plain Code makes one of a text, as Tag.Generate("Status.Debuff.Burn"). Its path Its path

One path always gives one unique name. So the padding only keeps a unique tag apart from the plain tag of its path.

IsValid says whether a tag has a name. An empty tag field holds default(Tag), which has none.

In this section

  • Its place in the tree: A tag's place in the tree comes from its Path, the text its family goes by.
  • Showing a tag: Show a tag by its display name, with ToString(), GetName() or an interpolated string, $"{tag}".
  • The registry: TagRegistry keeps the tags made as the game runs, by name.
