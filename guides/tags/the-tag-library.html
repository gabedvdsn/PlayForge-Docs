The Tag Library

A Tag Library asset, ForgeTagLibrary, declares tags for contexts, so those contexts' pickers offer them before any asset uses them. It also keeps the project's own contexts.

Create → PlayForge → Tag Library makes one. PlayForge also makes one in the active Forge Project's folder while there's none, as a tag is first declared or a context first made.

Its inspector, ForgeTagLibraryEditor, is the shared header over two lists:

Property Description
Entries The library's declarations, each a ForgeTagLibrary.Entry.
Contexts The project's own contexts.

Each entry declares one tag:

Property Description
Name The tag's name, padded where the tag is unique.
Display Name How the tag reads, where that differs from its name.
Contexts The contexts the tag is declared for. An empty list declares it Universal.
Note What the tag is for.

You seldom edit a library by hand. The Tags view's Declared For and New Tag's Contexts write its entries, each change one Undo step. A library edited by hand is read again as it's saved.

A declaration goes into the library that declares the tag already, or else into the first, by its path.

Every Tag Library in the Unity project is read, wherever it sits, and the contexts each keeps are every Forge Project's.

The tags a library declares are offered by the pickers of the Forge Project whose folder holds it. Another project's pickers offer them only where that project's own assets use them.
