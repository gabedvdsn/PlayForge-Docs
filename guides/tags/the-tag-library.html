The Tag Library

A Tag Library asset, ForgeTagLibrary, declares tags for contexts, so those contexts' pickers offer them before any asset uses them, and keeps the project's own contexts. Create → PlayForge → Tag Library makes one, and PlayForge makes one in the active Forge Project's folder as a tag is first declared, or a context first made, while there's none.

Its inspector, ForgeTagLibraryEditor, is the shared header over its two lists:

  • Entries, each a ForgeTagLibrary.Entry, a declaration: Name, the tag's name, padded where the tag is unique; Display Name, how it reads, where that differs from its name; Contexts, those it's declared for, an empty list declaring it Universal; and Note, what it's for.
  • Contexts: the project's own contexts.

The Tags view's Declared For and New Tag's Contexts write the entries, each change one Undo step, so a library is seldom edited by hand; one edited by hand is read again as it's saved. A declaration goes into the library that declares the tag already, or else into the first, by its path.

Every Tag Library in the Unity project is read, wherever it sits, and the contexts each keeps are every Forge Project's. The tags it declares are offered by the pickers of the Forge Project whose folder holds it, and by another project's only where that project's own assets use them.
