Injections

Kind Menu What it does
BreakStageRepeatInjection — Breaks out of a stage's repeat loop (for WithRepeat or RepeatUntilSkippedPolicy).
ChainInterruptInjection — Marker injection for chain-level interrupts.
DelegateSequenceInjection — An injection that does what a function of your own says: applyFunc is handed the run's runtime and returns whether it applied, as one that adds to a count on a key press or jumps to a stage by name.
InterruptSequenceInjection — Interrupts the entire sequence.
JumpToStageInjection — Jumps to a specific stage by index.
SkipAndMaintainInjection — Skips the current stage but maintains it running in background.
SkipStageInjection — Skips the current stage and moves to the next.
StopMaintainedAllInjection — Stops all maintained stages.
StopMaintainedAtIndexInjection — Stops the maintained stage at a stage index.
StopMaintainedLastInjection — Stops the oldest maintained stage.
