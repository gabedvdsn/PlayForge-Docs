Libraries

A lab's library, the assets it plays, is an ILabLibrary.

Library Where What it holds
EditorLabLibrary The editor Every asset of the project, and its Lab Scenarios. It saves scenarios.
ListLibrary Code The assets given, and the scenarios among them.
ListLibrary.Of(project) A game's own build The assets its Forge Project's catalog names. The lab plays it where no editor gives it a library.

A library offers projects to switch between through ILabLibrary.Projects, Project and UseProject, which have defaults.

  • Its ProjectAsset is the Forge Project it plays. While the scene names no project, the lab makes it current, so its units read its settings, as their combat logs do.
  • Its Scenarios, CanSaveScenarios, SaveScenario and DeleteScenario keep the lab's scenarios.

The lab's units run in a world of the lab's own, named "Creator Lab". The Debugger lists them beside the scene's entities.
