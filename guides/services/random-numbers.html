Random numbers

ForgeRandom is where PlayForge draws its random numbers: the game's rolls and random picks all draw from its source, an IForgeRandom.

  • The source is Unity's, UnityRandom, through UnityRandom.Instance, until code puts another in. It reads UnityEngine.Random, so Random.InitState(seed) seeds it, and anything else that draws from Unity's moves it. A SeededRandom, made with a seed, draws numbers of its own that nothing else draws from: two runs from one seed draw the same numbers.
  • ForgeRandom.Use(source) puts a source in and returns the one it replaced, and ForgeRandom.Use(null) puts Unity's back. ForgeRandom.Source is the one drawn from now.
  • It draws ForgeRandom.Value, from 0 to 1, as Random.value; InsideUnitCircle and InsideUnitSphere, a point within a radius of 1; Range(min, max) for floats; and Range(min, maxExclusive) for whole numbers, up to but not including the second, and the first itself where the range is empty.

What draws from it: every chance PlayForge rolls (Chance); auto targeting whose Mode is Random; a Randomized scaler's roll (Scalers: A magnitude field); ForgeHelper's random picks and points (ForgeHelper); and the Creator Lab. Cues don't: a placement's scatter and a floating text's random velocity draw from ForgeCues.Random, a SeededRandom of their own, so a cue never moves the game's rolls (Cues: Placement).

An IForgeRandom of your own gives Value, from 0 to 1, and InsideUnitCircle and InsideUnitSphere, a point in a circle and in a sphere of radius 1. A source put in stays until code puts another in, past the end of play mode where domain reload is off, so code that puts one in puts back the one it replaced.

using FarEmerald.PlayForge;

// A match's rolls from its seed: its replay, from the same seed, rolls the same
int seed = 20261118;
IForgeRandom previous = ForgeRandom.Use(new SeededRandom(seed));

int die = ForgeRandom.Range(1, 7);          // 1 to 6
float spread = ForgeRandom.Range(-5f, 5f);

// ... and, as the match ends
ForgeRandom.Use(previous);
