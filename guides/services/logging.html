Logging

ForgeLog is where everything PlayForge says goes: each message has a level and a system, and a gate on the two decides what reaches Unity's Console.

  • Levels, ForgeLog.ELevel, from the most said to the least: Verbose, Info, Warning, Error, and None, which lets nothing through, errors neither (Log levels).
  • Systems, ForgeLog.ESystem: General, Effects, Abilities, Attributes, Workers, Numbers, Processes, Tags, Items, Saves, Input, Lab and Sequences. Each can take a level of its own.

Code logs through it as PlayForge does:

  • ForgeLog.Verbose, ForgeLog.Info, ForgeLog.Warning and ForgeLog.Error take a message and the Unity object the Console points at, its context, as a message of General. Given a system first, they take the entity the message is about too, its subject, as ForgeLog.Warning(ForgeLog.ESystem.Abilities, "No target", this, gas).
  • ForgeLog.Exception(system, exception, context, subject) logs an exception as Unity's Debug.LogException does, its stack in the Console, where an error is let through.
  • ForgeLog.Allows(system, level) says whether a message would be let through, so a costly one is built only when it will be shown.

Its messages reach the Console with [PlayForge] before them, a warning as a warning and an error as an error. Its methods are marked [HideInCallstack], so the Console's Strip Logging Callstack leaves them out of the stack, and a double-click on a message opens the code that logged it.

ForgeLog.Logged hears each message let through, as a ForgeLogEntry: its Level, System and Message, without the prefix; its Context and Subject; and the game's Time and Frame as it was logged. An exception is heard as its type and its message. An entry's ToString() writes it in a line, as "Effects, warning: …". The Creator Lab's Log page hears the messages so.

using System.Collections.Generic;
using FarEmerald.PlayForge;
using UnityEngine;

// An in-game console: the last 50 warnings and errors PlayForge let through, newest last
public class ForgeConsole : MonoBehaviour
{
    private readonly Queue<string> lines = new Queue<string>();

    private void OnEnable() => ForgeLog.Logged += Heard;
    private void OnDisable() => ForgeLog.Logged -= Heard;

    private void Heard(ForgeLogEntry entry)
    {
        if (entry.Level < ForgeLog.ELevel.Warning) return;
        lines.Enqueue($"[{entry.Frame}] {entry}");
        while (lines.Count > 50) lines.Dequeue();
    }

    private void OnGUI()
    {
        foreach (var line in lines) GUILayout.Label(line);
    }
}
