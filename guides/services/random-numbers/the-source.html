The source

ForgeRandom draws from Unity's source, UnityRandom, through UnityRandom.Instance, until code puts another in. It reads UnityEngine.Random, so Random.InitState(seed) seeds it, and anything else that draws from Unity's moves it.

A SeededRandom, made with a seed, draws numbers of its own that nothing else draws from. Two runs from one seed draw the same numbers.

Method What it does
ForgeRandom.Use(source) Puts a source in, and returns the one it replaced.
ForgeRandom.Use(null) Puts Unity's back.
ForgeRandom.Source The source drawn from now. 
using FarEmerald.PlayForge;

// A match's rolls from its seed: its replay, from the same seed, rolls the same
int seed = 20261118;
IForgeRandom previous = ForgeRandom.Use(new SeededRandom(seed));

int die = ForgeRandom.Range(1, 7);          // 1 to 6
float spread = ForgeRandom.Range(-5f, 5f);

// ... and, as the match ends
ForgeRandom.Use(previous);

An IForgeRandom of your own gives Value, from 0 to 1, and InsideUnitCircle and InsideUnitSphere, a point in a circle and in a sphere of radius 1.

Note

A source put in stays until code puts another in, past the end of play mode where domain reload is off. So code that puts one in puts back the one it replaced.
