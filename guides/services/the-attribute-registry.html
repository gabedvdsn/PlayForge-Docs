The attribute registry

AttributeRegistry finds an attribute by its name, among those the game's entities have been given.

  • An attribute is registered under its name as an entity's attribute system takes it, and each attribute of the sets a Bootstrapper's Register Sets lists is registered as it brings PlayForge up. The first of a name keeps it: AttributeRegistry.Add(attribute) is false where the name is taken.
  • Names compare by AttributeRegistry.RefactorByNamingConvention(name), in capitals with each space an underscore, so "Attack Speed", "attack speed" and "ATTACK_SPEED" are one name.
  • AttributeRegistry.TryGetByName(name, out attribute) finds one, and AttributeRegistry.GetByName(name) gives it, or null; with createIfFalse: true, a name none has gives a new RuntimeAttribute of that name, which isn't registered. AttributeRegistry.Contains asks by a name or by an attribute's name, and AttributeRegistry.GetAll() lists them.
  • It starts empty each time the game starts, play mode with domain reload off among them, and AttributeRegistry.Reset() empties it, as the test kit's world does as it ends.
