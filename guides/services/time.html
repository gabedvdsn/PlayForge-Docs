Time

ForgeTime is the clock PlayForge's runtime reads in place of Unity's Time, and where a game puts in a time of its own.

It reads the clock in force, ForgeTime.Clock, an IForgeClock: Unity's, UnityClock.Instance, until code puts another in. Nothing else in the runtime reads Unity's Time. Its properties read that clock as Unity's own do:

ForgeTime As Unity's
DeltaTime Time.deltaTime: the frame's step, scaled
UnscaledDeltaTime Time.unscaledDeltaTime
FixedDeltaTime Time.fixedDeltaTime: the fixed step
Time Time.time: the time since the game started, scaled
UnscaledTime Time.unscaledTime
FrameCount Time.frameCount

ForgeTime.Use(clock) puts a clock in and returns the one it replaced, and ForgeTime.Use(null) puts Unity's back. Two things put a clock of their own in while they step, and the one before back after: each of ProcessControl's fixed ticks (Fixed ticks), and a world of its own, a ProcessWorld its owner steps with Step(deltaTime), whose clock reads that step.

An owner's time is its own where it has one:

  • ForgeTime.ClockOf(owner) is an entity's own clock for an entity, an IGameplayAbilitySystem, and the game's, GameClock.Instance, for anything else. ForgeTime.DeltaTimeFor(owner) is its step this frame.
  • ForgeTime.ClockFor(data) is the clock a data packet names, data.Clock, or else its owner's: an ability's caster's, or the game's. ForgeTime.DeltaTimeFor(data) is its step.
using FarEmerald.PlayForge;
using UnityEngine;

// PlayForge's time apart from Unity's: at a Scale of 0 every effect, cooldown and sequence on the game's time stands
// still, while Unity's own time, and all that reads it, runs on, and so does a sequence on the unscaled clock
public static class GameplayTime
{
    public static ScaledClock Clock { get; private set; }

    // Put in before the first scene loads, so all that keeps a time keeps it by this clock from the start
    [RuntimeInitializeOnLoadMethod(RuntimeInitializeLoadType.BeforeSceneLoad)]
    private static void PutIn()
    {
        Clock = new ScaledClock(1f, UnityClock.Instance);
        ForgeTime.Use(Clock);
    }
}

// A menu that stops the game's time sets GameplayTime.Clock.Scale to 0 as it opens, and back to 1 as it closes

A clock put in reads its time from somewhere else. GameClock, UnscaledClock, an EntityClock and a ScaledClock with no source each read the clock in force, so put in as it, each would read itself: ForgeTime.Use refuses the GameClock, and a ScaledClock over UnityClock.Instance, as above, scales Unity's. What waits until a time, as a pooled cue's burst does, keeps ForgeTime.Time, so a clock put in while the game runs should carry its Time on from the one it replaces. A clock put in stays until code puts another in, past the end of play mode where domain reload is off, so code that puts one in puts back the one it replaced.
