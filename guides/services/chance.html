Chance

ForgeChance rolls every chance PlayForge has, each by its ChanceRoll, which says whether it's pseudo-random and whose luck it reads.

PlayForge's chances are an effect's Chance to Apply, an ability's Chance to Activate, a trigger's Chance, a Value Pipeline's Chance, Block and Evade stages, and the Chance condition. ForgeChance.Roll(chance, in context, roll, key) says whether a chance, from 0 to 1, comes up for the caster its NumberContext gives. A chance of 1 or more always comes up and one of 0 or less never does, and neither draws, so a chance that can't miss leaves the numbers others draw as they were. Each of PlayForge's chances has a ChanceRoll beside it, its Chance Roll, Activation Roll or Roll, which says how it rolls (Effects: Requirements):

  • Pseudo Random: each miss raises the next roll's odds and a hit starts them again, so streaks even out while the chance over many rolls stays the same. The odds are ForgeChance.Constant(chance) times one more than the misses in a row, at most 1: the constant whose distribution's mean is the chance, as Dota's pseudo-random distribution is. Each caster keeps its own streak for each chance, by the chance's key, and PlayForge's own chances key by what holds them: the effect, the ability, the trigger, the stage or the condition. A pseudo-random roll with no key or no caster rolls its chance as it is. A caster's streaks go with it, and ForgeChance.ForgetStreaks(caster) forgets them, as a test does to start clean.
  • Luck: the roll's luck, ForgeChance.LuckOf(in context, roll). With Own Luck, it's the chance's own Luck, a number read for the roll; else it's the current value of the caster's attribute playing the project's Luck role, ForgeChance.ProjectLuck (Attributes: Roles); else 0. Either is rounded to a whole number. Above 0, the roll draws that many more times and keeps the best; below 0, the worst. A draw below the odds comes up.

The Chance condition, ChanceCondition, holds on a roll of its Chance, a number of any kind, as a critical strike chance read from an attribute, rolled by its Roll. Read in a hit, it rolls once and keeps the roll, so the hit's preview and its commit read the same; read with no hit, it rolls each time it's read.

A chance of the game's own rolls the same way:

using FarEmerald.PlayForge;

public static class Lockpicking
{
    // The key the thief's pseudo-random streak for this chance is kept under
    private static readonly object Key = new object();

    // Pseudo-random, and lucky by the thief's attribute in the project's Luck role
    private static readonly ChanceRoll Roll = new ChanceRoll { PseudoRandom = true };

    public static bool Picks(IGameplayAbilitySystem thief, float chance)
    {
        var context = NumberContext.Of(thief);
        return ForgeChance.Roll(chance, in context, Roll, Key);
    }
}
