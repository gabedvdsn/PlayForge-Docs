Entity services

An entity service is a per-entity object an entity's components share, made the first time it's asked for and stepped by the entity's own time. The auras an entity runs, AuraSet, and the wait a Respawn counts down, RespawnTimer, are two.

  • gas.GetService<T>() gives the entity's service of a kind, made the first time it's asked for, and gas.FindService<T>() gives it without making one, or null.
  • A service derives from AbstractEntityService, with a parameterless constructor, and overrides the hooks it needs, each a no-op otherwise: Step(deltaTime), each frame by the entity's own time, after its effects tick and before its turn; Revive(), as an entity that stays revives, before anything else of the revive; and End(), as the entity ends, which keeps none after. Its System is the entity it's of.

Entities: Services has the rest.

using FarEmerald.PlayForge;
using UnityEngine;

// A heat meter each entity keeps, which cools by the entity's own time: a slowed entity cools slower
public class Heat : AbstractEntityService
{
    public float Value { get; private set; }
    public float CoolingPerSecond = 10f;

    public void Add(float heat) => Value += heat;

    public override void Step(float deltaTime) => Value = Mathf.Max(0f, Value - CoolingPerSecond * deltaTime);

    // Back from the dead, cold
    public override void Revive() => Value = 0f;
}

public static class Overheat
{
    public static void Fire(IGameplayAbilitySystem gunner) => gunner.GetService<Heat>().Add(25f);

    public static float HeatOf(IGameplayAbilitySystem gunner) => gunner.FindService<Heat>()?.Value ?? 0f;
}
