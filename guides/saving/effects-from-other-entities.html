Effects from other entities

An effect knows what applied it: an entity, or one of its abilities or items. When that is another entity, the save needs a name for it that lasts. Give Capture and Restore an IForgeEntityIds, which maps the game's own IDs to its entities:

class Roster : IForgeEntityIds
{
    public string IdOf(IGameplayAbilitySystem entity) => /* the game's ID for it, or null */;
    public IGameplayAbilitySystem Find(string id) => /* the entity, or null if it's gone */;
}

var save = ForgeSave.Capture(hero, catalog, roster);
ForgeSave.Restore(hero, save, catalog, roster);

Without IDs, or when the other entity is gone, the effect comes back as the entity's own. An entity whose abilities are in their saved slots keeps them through its load, so several entities can load in any order and their effects on each other still name the abilities that applied them. Items aren't kept that way: when several entities load together, restore those whose items applied effects first, so the others find them.
