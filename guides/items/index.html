Items

An Item asset describes something an entity can hold and equip, such as a sword or a ring. An entity is anything that runs a gameplay ability system (GAS), such as the player or an enemy. Giving an item puts it in the entity's inventory. Equipping it applies what it grants: its Granted Effects, its Active Ability, its Granted Tags and its workers. Unequipping the item, or removing it from the inventory, takes them away again.

An entity gets items from its Entity asset's Starting Items, or from code through its ItemSystemComponent, with GiveItem, EquipItem, UnequipItem and RemoveItem. The entity's limits on items are set on its Entity asset.

Tags are names, such as State.Stunned, that an entity carries and that requirements check. Each asset stores a tag made from its Name: Iron Sword gives Item.IronSword. The entity carries this tag while the item is in its inventory, equipped or not, and keeps the item's level under it. Each section below matches the inspector section of the same name. A collapsed section shows one line about what it holds, such as the level range or how many effects the item grants.

The inspector's header shows the item's one line, as The Forge's Summary column does: what each effect it gives changes while it's equipped, by its first impact across its levels, then the ability it grants, as "+20 Armor; Blink".

In this guide

  • Identity: Name: the item's display name.
  • Leveling: An item has its own level on each entity that holds it, kept under the item's asset tag.
  • Tags: Context Tags describe the item, such as Weapon.
  • Effects: Granted Effects are applied to the entity while the item is equipped.
  • Abilities: Active Ability: an ability the entity learns while the item is equipped.
  • Components: An item's components are features it carries, each a class with hooks into its life, added with the list's +.
  • Workers: Workers are reusable behaviours, picked from a list, that react to what happens to an entity.
  • Local Data: Local Data is a list of named values stored on the asset.
  • Used By: The PlayForge assets that refer to this item, each with its type icon, such as an entity that starts with it or an effect linked to it.
  • Built-in kinds: The kinds PlayForge ships for this guide's pickers, each with its menu and what it does, as its picker says.

In the API

The types of this guide's area: EItemLinkMode, Item, ItemCallbackStatus, ItemDefinition, ItemSpec, ItemSpecContainer, ItemSystemCallbacks, ItemSystemCallbacks.ItemConsumedDelegate, ItemSystemCallbacks.ItemSystemCallbackDelegate, ItemSystemComponent, ItemTags, SetBonusItemComponent, UsesItemComponent.
